- lr664 は lr より回収率の点推定が約 2pt 高い(lr50 → lr664_50 が +2.0%、lr100 → lr664_100 が +2.4%)。95% 区間は −7.1%〜+11.3% と −8.5%〜+12.6% で、0 をまたぐ。

- 数は N=500 レースで、回収率の差には上の区間がつく。下位桁に意味を読まないこと。

## 読み
学習モデルに特徴量を足すと、確率の当たり具合はわずかに良くなる(見込み/実が 1.08 から 1.05 へ)が、回収率は cur を上回らない。規則は固定のとおり「進まない」。
