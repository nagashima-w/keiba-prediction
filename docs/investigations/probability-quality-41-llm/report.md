## 4. 読み方(計画 §9 のとおり。閾値は置かない。断定しない)

- **LLM の補正が確率の質を変えたか(§3.2)**:
  - **中央**: 全レースの BS 差は -0.0017〔-0.0056, +0.0023〕。区間は 0 を含む。「この標本では、prior との差を区別できない」。
    市場比較可能な集合(21R)でも -0.0027〔-0.0067, +0.0013〕 で、区間は 0 を含む。
  - **地方**: 全レース(= 市場比較可能な集合、12R)の BS 差は -0.0094〔-0.0169, -0.0022〕。区間は 0 を含まない。
    この標本では、LLM 補正後のほうが Brier が小さい(点推定で prior の 5.1% 小さい)。ただし、レース数は 12 で、区間は LLM のサンプリングのばらつきを含まない。別の回の応答では変わりうる。
  - 比 `1 − BS_LLM/BS_prior` は中央 +0.0104・地方 +0.0507(いずれも小さい値で、下位桁に意味を読まない)。
- **識別力(RES と並べ替えの参照値、§3.1)**: resolution が並べ替えの 95 点を超えるか — 中央 prior 超える・
  中央 LLM 超える・地方 prior 超える・地方 LLM 超える。
  RES は prior → LLM で 中央 0.0129 → 0.0140・地方 0.0246 → 0.0439。
  reliability(REL)は 中央 0.0017 → 0.0022・地方 0.0112 → 0.0214。
  各帯の件数は数件〜数十件で、REL・RES は小標本で偏るため、上の値の下位桁・小さな差に意味を読まない。
- **対市場(§3.3)**: prior・LLM のいずれも、中央・地方とも、BS 差(model − market)の下限版の区間は、0 を含まず、正の側にある(この標本では、モデルの Brier が市場より大きい)。
  中点版でも同様に区間は 0 を含まず正の側。LLM 補正で市場との差の点推定は小さくなったが、市場より Brier が小さくなった系列は無い。
- **方向性(§3.6)**: 補正の向きは、市場の方向とある程度そろっている(符号の一致: 中央 68.7%・地方 64.1%。
  プールした相関は中央 0.517・地方 0.505)。一方、市場まで寄せたわけではない(傾きは中央 0.134・地方 0.119。1 なら市場まで)。
  市場までの距離の平均は 中央 0.1149 → 0.1029・地方 0.1436 → 0.1305 と縮んだ。
  **これは記述であって、「迎合した」「しなかった」とは断定しない**(市場は馬の力量の情報を含むため、プロンプトのデータから力量を判断した補正も市場と同じ向きになりうる。両者は区別できない)。
- **補正の大きさ(§3.5)**: δ の絶対値の平均は 0.03 台で、上限 0.10 に達した馬は 2 頭だけ。レースごとの Σ補正後確率は、目標 min(3, 頭数) より中央値で
  中央 -0.0500・地方 -0.0650(レンジ 中央 -0.3400〜+0.0900・地方 -0.3200〜+0.1200)。
  production は補正後確率を再正規化しないので、この Σ のずれは EV 計算にそのまま入る。
- **「#35-2/#42 に進む/進まない」は書かない。** この結果を判断に使う場合は、(1) サブエージェントが production の LLM と同一でない近似であること、
  (2) 確定オッズがプロンプトに入っていること、(3) 標本が小さいこと、(4) 区間が LLM のサンプリングのばらつきを含まないこと、を併記すること。
