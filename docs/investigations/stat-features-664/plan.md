# #664 計画: #663 の条件を学習モデルの特徴量に足し、保留で評価する(結果を見る前に固定)

**状態: 計画。この文書と道具(`scripts/stat-features-664/`)をコミットしてから、保留(2026-08〜10)を開く。** 本番のコード(`packages/core/src`・`cloud/src`)は変えない。

## 1. 保留について(先に書く)
保留の期間には、すでに 3 回触れている。結果を読むときはこの点を差し引く。
1. #649 の評価で一度開けた。
2. #662 の試算で、保留に入る中央 9〜10 月の 545 レースを使った(学習は保留を捨てて学び直した)。
3. #663 の「確認の期間」(2021-01-01〜2026-11-03)に保留の期間が入っている。**条件を「残った」と判断した材料に、保留の期間の集計が入っている**(1 条件ごとの粗い集計で、馬ごとの結果ではない)。
   この 3 つ目は評価をやや甘くしうる。条件の選択そのものが保留の期間を一部見ているため。

そのため、**この評価は「保留を一度も見ていない評価」ではない**。決め方は下の §5 のまま変えず、結果は「足した後が悪くなっていない・少し良い」程度の読みに留める。保留をもう一度使わないために、結果を見てからの特徴量・設定の変更はしない(変えるなら新しい期間か、5 年分がそろってから)。

## 2. 特徴量の定義(`features.ts`。hist から作る旗。すべて 0/1)
材料は手元の過去の結果 hist(中央のみ。2024-08〜)。前走は、その馬の hist 内の**直近の 1 走**(障害を含む。取消・除外は走ったことにしない)。

| 旗 | 定義 | 備考 |
|---|---|---|
| noprev | 前走が hist に無い | 初出走、または前走が地方・海外。**hist は中央のみなので、前走が地方・海外の馬は、hist に前走が無ければ「前走なし」になる。ただし、さらに前の中央の走が hist にあれば、その走を前走と取り違える(休み明けが長く出る側の誤り)。避ける手段は手元に無い** |
| turf2dirt / dirt2turf | 前走が芝で今走がダ / 前走がダで今走が芝 | 前走が障害なら 0 |
| rest180 | 前走から 180 日以上 | 日数は障害の前走も含む |
| mid1w | 前走から 8〜14 日(連闘の 7 日以内は含めない) | |
| distUp400 | 今走の距離 − 前走の距離 ≥ 400m | 前走が障害なら 0 |
| filly | 牝 | セン馬は 0 |
| age7 | 7 歳以上 | 年齢が欠ければ 0 |
| wLight / wHeavy | 馬体重 420kg 未満 / 520kg 以上 | 欠ければ両方 0(欠けは 0.3% 以下) |
| eastInWest | 美浦の厩舎の馬が、京都・阪神・中京・小倉で走る | 札幌・函館はどちらにも入れない |
| westInEast | 栗東の厩舎の馬が、東京・中山・新潟・福島で走る | 同上 |
| foreignJC | 前走と騎手 ID が違い、今走の騎手名がカタカナだけ | 騎手名は 3 文字に切れている。日本在住か短期免許かの区別はできない(#663 の H03 は両方を含むので定義は合う)。前走の騎手 ID が無ければ 0 |
| foreignJCnoLemaire | foreignJC のうち、騎手名が「ルメ」で始まる(ルメール)を除く | 参考表だけに使う |
| gain4 | 前走の 4 角(通過順の最後)− 前走の着順 ≥ 5 | 前走が障害・通過順か着順が無ければ 0 |

- 前走を使う旗(turf2dirt・dirt2turf・rest180・mid1w・distUp400・foreignJC・foreignJCnoLemaire・gain4)は、前走なしのとき 0。「前走なし」は noprev で区別する。
- **外す条件**: 女性騎手(hist に性別の列が無く、騎手 ID の手書きの一覧は正しさを確かめられない)。見習騎手の減量は、#652 の `mk_`(印 5 種)をそのまま使い、新しい旗は足さない(重複を避ける)。
- 4 角の押し上げの定義(通過順の最後 − 着順)が BASHIRA の `gain_from_corner4` と同じかは、確かめていない。
- 付録に、外国人とみなした騎手名の一覧(日本人が混ざっていないかを目で確かめた結果)を載せる。

## 3. 比べるモデル
学習は 2025-02〜2026-07 に**固定**し、保留の 2026-08〜10 を一度に予測する(月ごとに学び直さない)。前処理・学習は `scripts/stat-model-649/fit.py` と同じ(標準化 + L2・C=1.0、使うレースの条件、5 頭未満のレースは外す)。目的は win / top2 / top3 を別々に学習し、レース内で合計が 1・2・3 になるロジットシフトで確率にする。

- 足す前: オッズなし版 `noodds_base`(log_n・prior_logit・15 寄与)、オッズ入り版 `odds_base`(それに m_logit)。係数が fit.py(保留なし)の `importance.json` の `lr_noodds`・`lr_odds` と一致することを、先に `--repro` で確かめる。
- 足した後: `noodds_all`・`odds_all`。足す特徴量は、noprev・turf2dirt・dirt2turf・rest180・mid1w・distUp400・filly・age7・wLight・wHeavy・eastInWest・westInEast・foreignJC・gain4(14 個)と、#652 の見習の印 `mk_▲ mk_△ mk_☆ mk_◇ mk_★`(5 個)。
- 参考(決め方には使わない): 旗を 1 つずつ足したモデル `*_only_<旗>`(前走を使う旗は noprev も一緒に入れる)、見習の印だけ `*_only_mk`、印を除いた全部 `*_all_noMk`、foreignJC をルメール除きに替えた全部 `*_all_noLemaire`。

## 4. 指標
- 頭あたりの対数損失(勝ち・2着内・3着内)。確率は [1e-6, 1−1e-6] に切る。
- 差 = 足した後 − 足す前(負が良い)。レース単位のブートストラップ(1,000 回・シード 664)の 95% 区間(2.5%〜97.5%点)。
- 人気の帯(1〜3・4〜9・10 番人気以下。確定単勝オッズの順位)ごとの 実際 / 見込み(見込みはその帯の確率の合計)。

## 5. 決め方(Issue のとおり。追加の条件は置かない)
`noodds` の組と `odds` の組を、**それぞれ別に**判定する。
- 「悪くならない」= 3 指標(勝ち・2着内・3着内)のどれでも、差の点推定が 0 以下。
- 「良くなる」= 少なくとも 1 つの指標で、差の 95% 区間の上限が 0 より小さい。
- 両方を満たす組は「段階 2 に進む候補」。満たさない組は進まない。
- 2 つの組の判定の多重補正はしない(2 組あることを結果に書く)。人気の帯ごとの 実際 / 見込みは読み物で、判定には使わない。
