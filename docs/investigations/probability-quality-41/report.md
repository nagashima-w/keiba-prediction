## 3. 読み方(計画 §5.3 のとおり。閾値は置かない)

- **識別力(モデル単独)**: 全レースで見たモデルの resolution は、レース内で結果を並べ替えた参照値の
  95点を **上回った**(中央 0.0129 > 0.0108、地方 0.0246 > 0.0137)。この標本では、並べ替えと区別できる
  レース内の識別力がある。一方、大きさは小さい(RES/UNC は 中央 0.074・地方 0.122)。
  同じ集合での市場の resolution と比べると、モデルは 中央 約 22%(0.0075/0.0337)、地方 約 33%(0.0246/0.0742)。
  「resolution が 0 に近い」とは言えないが、**市場の識別力にはるかに及ばない**。
  (参照値は全レースで計算した値。中央の比較集合に絞った参照値は算出していない。)
- **対市場**: BS 差の95%区間は中央・地方とも**0を含まない**(モデルの Brier が市場より悪い側)。
  Brier skill(対市場)は 中央 −0.185・地方 −0.362。中点版でも同じ向き(−0.182・−0.388)。
  区間はレース数(中央21・地方12)を反映した幅で、標本が小さい。
- **較正(REL)**: モデルの reliability は小さい(中央 0.0017・地方 0.0112)が、地方は帯ごとの件数が少なく、
  [0.2,0.3) 帯(44件。予測 0.254・実際 0.159)と [0.4,0.5) 帯(12件。予測 0.430・実際 0.667)のずれが
  効いている。**件数が少なく下位桁に意味を読まない**。
- **分布の形**: モデルの確率は市場より大幅に平らで(max/min 比 中央値は 3.2・2.3 に対し市場は 25.9・26.9。
  sd 比の中央値は 0.45・0.38。正規化KL の中央値は 0.043・0.026 に対し市場は 0.22・0.22)、
  順位は市場と正の相関を持つ(ρ の中央値 0.64・0.54)。#35 の n=2 の観察(中央は市場の38%・順位無相関、
  地方は市場と同等)とは**異なる**: 今回の24・12レースでは、中央・地方とも sd 比は 0.4 前後で、ρ は正の相関だった。
  (旧観察はリークありの値を含み、条件も異なる。)
- **n は小さい**: 中央 24 レース・地方 12 レース(馬は 321・128頭)。地方は **1日・1会場(門別)**、
  中央は **2日・1会場(中山)**(障害戦1レースを含む)。他の会場・季節・クラスへの一般化は、この標本からはできない。

## 4. リーク経路の一覧

**遮断したもの**
- 戦績の自レースの走・施行日以降の走(#39。`runAnalysis` が遮断)。計測側の診断値(生の戦績に
  `filterRaceDataBefore` を掛けた値)では、除去件数が **観測した馬の数と一致**した(中央 321 = 321頭・
  地方 128 = 128頭。全馬の戦績から**自レースの1走だけ**が基準日以降として除かれた。基準日より後の走は 0 件。
  取得は開催の数日後で、観測した馬が再出走していなかったため)。診断値は計測側が生の戦績に掛けた値で、
  `runAnalysis` が(自レースを先に除いてから日付で絞るため)内部で除いた件数と内訳は一致しない場合がある。

**本測定では無関係なもの**
- LLM プロンプト側の先読み(同日傾向・重賞の過去結果): LLM を使わないため関係しない。
- 騎手コース成績: `jockeyCourseStats` は production の `runAnalysis` から渡されない。
- オッズ: prior は使わない(予測の入力ではない)。比較対象の市場は確定オッズで、発走前に確定する情報だが、
  prior より後に確定する値であり、情報量は市場の方が多い(発売の最終状態を反映する)。

**遮断できず残るもの(定量はしていない)**
- 馬場状態・馬体重増減・騎手・斤量は**取得時点(発走後)の値**。発走前の値と異なる可能性がある
  (直前の馬場の変化・乗り替わりなど。大きさは測っていない)。
- **取得した出馬表に取消馬が載ったままだった**(中央1頭)。結果ページで取消と分かる馬を、prior を計算する前に
  除いた(発走前に確定する情報のためリークではない)。
- 結果ページの着順・払戻は prior の入力に使っていない(観測の分類にだけ使った)。

## 5. 限界・想定外

- 想定外の取得失敗・停止・未知の着順文言は**なかった**(計画の「取得後の追記」は空のまま)。
- 地方のオッズの `middle` を確定後と見なしたのは、結果ページの確定と取得日時による推定(ページ上の根拠はない)。
- 市場確率は下限(または中点)からの近似で、複勝の払戻の幅と控除を含む。人気薄ほど幅が広い差は
  正規化後も残る(中点版との差は上の表に出した)。
- resolution の参照値は全レースのもの(比較集合別には出していない)。
- 馬は同一レース内で独立でない(Σ=3)。区間はレース単位の再標本だが、レース数が少なく、会場・日も限られる。
