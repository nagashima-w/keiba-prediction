## 3. 読み取れること
- **Issue の見立ての確認**: F0(本番と同じ形)のずらし前は、1 番人気で 1.0〜1.9 倍が O/E 1.045(z +4.3)、6〜9 番人気 1.039(+3.1)、10 番人気以下 0.971(−1.4)。#688・#689 の数値(1.049・1.039・0.958)と同じ向きで、同じ水準に再現した(それらの係数は別なので完全な一致ではない)。
- **ずらしで一部が打ち消される**(Issue の推測の確認): F0 の 1.0〜1.9 倍の帯は、ずらし前 1.045 → ずらし後 1.009(z +0.9)になる。6〜9 番人気は 1.039 → 1.040 でほぼ打ち消されない。10 番人気以下は 0.971 → 0.976。
- **F1・F3 は 6〜9 番人気を少ししか直さず(1.040 → 1.027)、1.0〜1.9 倍の帯はずらし後に悪化する**(1.009 → 1.027、z +2.7)。F1・F3 の D が下がるのは、1 番人気・10 番人気以下の帯が 1 に寄るため。
- **F2 だけが 6〜9 番人気(1.003)も直す**。残るのは 10 番人気以下 1.024(z +1.1)。節ごとの傾きの変化(F2 の係数)が効いている。ただし F2 は係数 6 個で、評価の期間の帯でなく当てはめの期間の分位で節を固定したので、評価での選択はしていない。
- **F1 と F3 はほぼ同じ**(L·ln n を足しても変わらない)。
- **F_prod は F0 よりわずかに良い**が、F_prod の係数は 2024-11〜2026-11 で当てはめたもので、**評価の期間の大半と重なる(評価に有利な比較)**。それでも差は小さい(ずらし後の対数損失 −0.000005)。つまり当て直しの効果は無い。
- 効果の大きさ: 対数損失の改善は F1 で 0.037%、F2 で 0.099%。市場の見込みの式は元から良く合っていて、**直せるのは帯ごとの数 % のずれ**。
