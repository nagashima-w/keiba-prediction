- **対象馬** = 対象レースの、取消・除外でなくオッズのある馬。**頭数 n = オッズのある馬の数**(本番の `marketPlaceProbs` と同じ)。オッズの無い馬は行にも n にも入れない。そうしたレースの数を報告する。

- q = 1/単勝オッズ をレース内で合計 1 に割り戻した値(本番と同じ)。L = logit(q)(本番と同じく [1e-6, 1−1e-6] で挟む)。確定オッズを使う(分析の時点のオッズより鋭い。限界に書く)。

## 3. 式の候補(固定。5 つ)
どれも m = sigmoid(特徴量 · 係数)。ロジスティック回帰(罰則なし)で当てはめる。F_prod だけは当てはめない。
| 名前 | 特徴量 | 係数の数 |
|---|---|---|
| F_prod | 1, L, ln n(係数は本番の [2.857, 0.9216, −0.5561] のまま) | 3(固定) |
| F0 | 1, L, ln n(当てはめ期間で当て直す) | 3 |
| F1 | F0 + L² | 4 |
| F2 | 1, L, ln n, max(0, L−k1), max(0, L−k2), max(0, L−k3) | 6 |
| F3 | F1 + L·ln n | 5 |
- F2 の節 k1,k2,k3 = **当てはめ期間の対象馬の L の 20・50・80 パーセンタイル**(馬単位。線形補間なしの順位統計量: 昇順に並べた m 個の `floor(0.2·(m−1))`・`floor(0.5·(m−1))`・`floor(0.8·(m−1))` 番目)。当てはめの前に固定して `fit-coef.json` に書く。
- 「単純さ」の順(同じ基準を満たす候補が複数あるとき、先のものを選ぶ): F0 < F1 < F3 < F2(係数の数 3・4・5・6)。F_prod は比べる基準(参考)で、選ぶ候補ではない。
- 当てはめは Newton 法(30 回、収束の許容 1e-8)。数値計算は numpy を使ってよい(#688 は標準ライブラリだが、行数が 100 万を超えるため)。

## 4. 評価の物差し(評価の期間で、式ごとに 1 回だけ)
- **(a) 対数損失**: 対象馬の平均。式の組の差は、レース単位の合計の差から標準誤差(記述)を付ける。
- **(b) 人気の帯ごとの O/E と z**: 帯 = 確定人気(`ninki`。null なら単勝オッズの昇順の順位)の 1 / 2〜3 / 4〜5 / 6〜9 / 10 以下、加えて 1 番人気で単勝 1.0〜1.9 倍(1 番人気の部分集合。重なる)。O = 帯の 3着内の数、E = m の合計、z = (O−E)/√(ΣE(1−E))(馬を独立とみなす近似)。
- **(c) 共通のずらしを入れた後の (a)(b)**: レースごとに、logit(m) に全馬共通の定数 d を足して Σ sigmoid(logit(m)+d) = min(3, n) となる d を二分法で求め(本番の `shrinkTowardMarket` の最後の段と同じ。ここでは p を混ぜず m だけ)、その値で (a)(b) をやり直す。**本番は p と混ぜたあとにずらすので、これは「m だけにずらしを入れた」近似**(混ぜたあとの p' の帯ごとのずれは、配分の試算〈§6〉で見る)。
- **ずれの要約** D = 6 つの帯(上記 5 帯 + 1.0〜1.9 倍)の |O/E − 1| を、帯の対象馬の数で重みをつけて平均した値。5 帯だけ(重ならない)の値も併記する。決定には 6 帯の値を使う。

## 5. 合否の基準(固定)
候補(F1・F2・F3)が F0 に対して、**(c) で、対数損失が小さく、かつ D(6 帯)が小さい**。両方を満たす候補のうち、§3 の順で最も単純なものを選ぶ。満たすものが無ければ「本番の形のまま当て直すだけでよい(または何もしない)」と結論する。点推定の大小で判定し、標準誤差は参考(判定に使わない)。(a)(b) のずらし前の値と、F_prod と F0 の違い(当て直しの効果だけ)も報告する。
- 事前の注意: 差が標準誤差より小さければ、真の差の有無は区別できない。その場合も上の規則で選ぶが、報告に「雑音と区別できない」と書く。
