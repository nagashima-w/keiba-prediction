## 3. 比べるモデル(目的は勝率・2着内率〈2着以内〉・3着内率の 3 つ。目的ごとに別に学習)
| 記号 | 内容 |
|---|---|
| (i) 現行 | prior(3着内率)を Plackett–Luce で換算した勝率・2着内率。3着内率は prior そのもの。学習なし |
| (0) 市場そのまま | 1/確定単勝オッズをレース内で合計 1 にした値(勝率)。2着内率・3着内率は同じ値をロジットシフトで合計 2・3 に合わせたもの |
| (ii) 市場だけ | logit(q) + log(頭数) のロジスティック回帰。市場の基準(#548・`market-edge-calc.ts` と同じ形) |
| (iii) 案 L | (ii) に logit(prior) と 15 項目の寄与(補正値)を足したロジスティック回帰 |
| (iv) オッズなし | (iii) から logit(q) を外したもの |
| (v) XGBoost | (iii) と同じ入力の勾配ブースティング木。手元の比較と SHAP のためだけ |

- ロジスティック回帰は標準化した特徴量・L2(C=1.0)で固定。XGBoost は `fit.py` 冒頭の値(木 300 本・深さ 3・学習率 0.03・min_child_weight 50 ほか)で固定。**調整しない。**
- 予測のログオッズは、レースごとに全馬に共通のロジットを足して合計を 1・2・3 に合わせる(`lib.ts` の `normalizeLogitShift`)。勝率 ≤ 2着内率 ≤ 3着内率の整合は、試験の期間で破る馬の割合を数える(非保留の試験では 47,546 頭のうち、XGBoost で 1 頭、ほかのモデルは 0 頭)。
- 入力のオッズは**確定オッズ**で、分析の時点(発走の約 45 分前)より情報が多い。市場を入れるモデル((ii)(iii)(v))に有利な比べ方になる。

## 4. 評価
- 時間順: 試験の月ごとに、その月より前の全部(2025-02〜)で学習して、その月を予測する(拡大窓)。
- **主指標**: 目的ごとの対数損失(試験の月をまとめる)。(ii) との差と (i) との差を、レース単位のブートストラップ(1,000 回、シード固定)の 95% 区間で見る。
- 市場への係数: y ~ 1 + logit(モデル) + logit((ii)) のロジスティック回帰で、モデル側の係数と z。
- 副次: Brier、月ごとの対数損失、単勝の回収率(確率 × 確定オッズ > 1 の馬に 1 ずつ。区間はレース単位)。回収率は雑音が大きいので判断の根拠にしない。
- SHAP(XGBoost)と標準化した係数(ロジスティック回帰)で、効いている項目の順位を出す(非保留の全期間で学習)。

## 5. 判断の目安(案。数値はユーザーと決める)
判断は保留の期間の値で行う。「改善」は、(A) 対数損失の差(A−B)の 95% 区間の上限が 0 より小さく、かつ (B) 平均の差が −0.0005 より小さい(頭あたり)こと、とする案。
−0.0005 は、§7 の非保留での (iii)−(ii) の差(絶対値で 0.0003 以下)より大きい値として置いた。

1. **直接 > 換算**(市場なし): (iv) が (i) に対し、3 目的すべてで「改善」。
2. **影の並走に進む**: (iii) が (i) に対し 3 目的すべてで「改善」し、(ii) に対して「悪化」でない(差の区間の下限が +0.0005 を超えない)。
3. **買い目に使う**(#651 以降): (iii) が (ii) に対し勝率で「改善」し、市場への係数が正で z > 2。
   単勝の回収率は、区間が 1 を含まない場合に限って補強に使う。
4. 2 が成り立たなければ、直接の見積もりの出し方(目的ごとの写像)だけを見直して、再度事前登録する。
