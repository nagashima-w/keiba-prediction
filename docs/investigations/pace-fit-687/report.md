# #687 報告: 馬ごとの展開の向き不向きと予想した展開。向く馬は市場の見込みより 3着内に来るか

**結論: 探索 B(2022-01-01〜2023-12-31)で、候補(群の頭数 ≥ 300 かつ BH q < 0.05)は 0 件だった。計画 §5 により確認の期間(2024-01-01〜2026-11-01)は開いていない。「向く馬が市場より来る」「向かない馬が市場より来ない」のどちらも、市場の見込みに対して見えなかった。**
そもそも、馬ごとの向き不向きの点 D は、過去走を交互に 2 つに分けた相関が 0.014 で、馬ごとの情報が乏しい(下記)。

## 1. やったこと(計画 `plan.md` と追記 1・追記 2 のとおり)
- データ: 手元の中央の過去の結果(2021-06-20〜2026-11-01、18,519 レース)。過去走は hist の中だけ。BASHIRA・netkeiba・本番の D1/R2・実 API は呼んでいない。
- 探索 B の対象 5,895 レース(うち展開の予想がある S 寄り 1,965・H 寄り 1,965、中間 1,965)。2021-06〜12 は助走。
- 市場の見込み: 探索 B で当て直した係数 [2.6673, 0.9162, −0.4918](82,341 頭、O = E = 17,694 で較正は合っている)。#683 の案 B [2.6574, 0.8926, −0.5093] に近い。
- π(コースの基準のペース割合)は、courseType × 競馬場 × 実距離 × 内外回り(根は courseType × 距離 6 段、縮めは m = 30)にクラスの掛け合わせ。区分は 競馬場・実距離 101(30 レース未満 29)、内外回り 104(同 33)、クラス係数 35(同 11)。
- k は経験ベイズで τ̂² = 0.0014、σ̂² = 0.145 から k_raw = 103 となり、上限 20 に張り付けた。k を 0.5 倍・2 倍にしても D の相関は 0.997 以上(D の散らばり sd は 0.039・0.022・0.012)。
- D の信頼性(走が 4 本以上の 9,859 頭、交互分割): 傾き D の相関 0.014、切片 L の相関 0.005。**ほぼ 0。D は馬ごとの安定した差を捉えていない**(計画どおり、評価は最後まで流した)。
- 展開の予想(探索 B の中。当てはめの範囲を含むのでサンプル内): S 寄りのレースの実際の S 率 33.2%(基準だけの予想 26.7%)、H 率 25.1%(同 29.0%)。H 寄りは S 率 11.0%(同 17.6%)、H 率 46.0%(同 40.6%)。基準より片側に動くが、動きは 4〜7 ポイント程度。

## 4. Issue の問いへの答え
- 予想した展開に向く馬が、市場の見込みより 3着内に来るか: **見えなかった**。D 自体に馬ごとの再現性が無い(交互分割の相関 0.014)ので、点がほぼノイズだった可能性が高い(推測。真の差が小さいか、過去走が少なすぎるか〈過去 2 年で Σδ² の中央値は 1.1〉の区別はつかない)。
- 本番に使う形: 今回の結果では、確率の補正・見送りのルール・LLM への材料のいずれも、新しく足す根拠は得られなかった。
- 回収率・ハンデ戦の分割・確認の期間: 候補が無いので出していない。

## 5. 限界
1. 過去走は hist の中(2021-06-20 以降)だけ。D の元データが薄い。2021 年より前の取得はしていない。
2. 確定オッズ(本番より見込みが鋭い)。z は馬の独立を仮定した近似。
3. 展開の予想の基準だけのモデルは、π を当てはめと同じレースから作るので、サンプル内。
4. 馬場状態は無視。内外回りは `courseDetail` の「外」の有無に頼る(表記のゆれは確かめていない)。
5. 期間は #683〜#686 で別の仮説に使用済み(結果と無関係な期間は無い)。
6. k が上限 20 に張り付いたので、D は強く縮められている(τ̂² がほぼ 0 という推定の帰結)。k を弱めても点の信頼性は上がらない(推測)。
