## 2. 「荒れた」の定義と、BASHIRA でレース単位を作る方法
BASHIRA は 1 行 = 1 出走。レース単位の指標は、**1 番人気(`win_odds_rank = 1`)の行だけを集計する**と 1 行 = 1 レースになることを使う(同オッズの 1 番人気が 2 頭いる場合は 2 行。ごく稀で無視する)。

| 区分 | 定義 | 取り方 |
|---|---|---|
| **主(A)** | **1 番人気が 4 着以下(3 着内に入らない)** | `win_odds_rank: 1` の行で、3着内数(`official_result ≤ 3`)と starts から 4 着以下 = starts − top3。**レース単位の厳密な二値**。主の検定はこれだけ |
| 副 1(S1) | **勝ち馬が 6 番人気以下** | `win_odds_rank` を dimension に置いた集計で、6〜18 番人気の勝ち数の合計 ÷ レース数(= 勝ち数の合計)。レース単位の厳密な二値 |
| 副 2(S2) | 1〜3 番人気の 3着内の頭数の平均(0〜3) | 同じ集計から、1〜3 番人気の 3着内数の合計 ÷ レース数。平均なので検定はしない(記述のみ) |

三連単の高配当そのものは get_races の払戻を 1 レースずつ取らないと作れず、網羅的な取得になるので使わない。A・S1・S2 を「荒れ」の代理にする(代理であって、高配当との対応は未検証と報告に書く)。

## 3. 母集団・期間・検定
- JRA の芝・ダート(障害は除く)。クラスは全部(新馬・未勝利・1勝〜3勝・オープン。重賞は grade で見る)。
- 探索 2016-01-01〜2020-12-31、確認 2021-01-01〜2026-11-03(データの最終は確定済みの分まで)。
- 検定の単位は「材料(X)の 1 水準」。**主の検定(A)は、1 番人気の行をクラス(`race_condition`)× 材料の 2 次元で集計**し、
  - 水準 L の実測の率 p_L = 4 着以下の数 / レース数、
  - 期待 E = Σ_クラス n_{L,クラス} × p_{クラス, L 以外}(同じクラスの、L 以外のレースの率)、
  - z = (O − E) / sqrt(Σ n p̂(1−p̂) (1 + n_{L,c}/m_{rest,c}))(2 群の比較の分散。基準側の誤差も入れる。p̂ はクラス内のプール率)。
  とする。クラスを層にするのは、クラスと荒れやすさ・頭数の関係が強いため。芝ダは層に入れられない(dimension が 2 つまで)ので、芝ダに偏る材料(馬場状態・天候など)は芝ダの差が混ざる。**発走前に分かる材料として使えるかを見る調査なので、混ざることは許容し、報告に書く。**
- 基準はその期間の全レース(`ALL`、クラス別)から水準 L を引いたもの。材料が 1 回の集計で全水準を返すとき(dimension に置ける材料)は L 以外 = ALL − L。

## 4. 発走前に分かる材料(事前登録。結果を見る前に固定)
1 行が get_stats 1 回(主の検定 A)。`win_odds_rank: 1`、芝ダ、クラス全部、期間は共通。dimensions は `["race_condition", X]`(帯で切る材料は filters を変えて dimensions は `["race_condition"]`)。

| # | 材料 | 水準(検定の単位) | BASHIRA の書き方 |
|---|---|---|---|
| X01 | 芝ダ | 芝 / ダート | dimension `surface` |
| X02 | 距離 | ≤1400 / 1500〜1800 / 1900〜2200 / ≥2300(集計後に分類) | dimension `distance` |
| X03 | 馬場状態 | 良 / 稍重 / 重 / 不良 | dimension `track_condition` |
| X04 | 天候 | 晴 / 曇 / 雨 / 小雨 / 雪など | dimension `weather` |
| X05 | 開催月 | 1〜12 | dimension `race_month` |
| X06 | 競馬場 | 10 場 | dimension `race_track` |
| X07 | 重量種別 | ハンデ / 別定 / 馬齢 / 定量 | dimension `weight_type` |
| X08 | 競走種別 | 2歳 / 3歳 / 3歳以上 / 4歳以上 | dimension `race_type` |
| X09 | 曜日 | 土 / 日 / 祝日ほか | dimension `day_of_the_week` |
| X10 | 格付け | G1 / G2 / G3 / L / その他重賞 / 平場 | dimension `grade` |
| X11 | 柵 | A / B / C / D | dimension `rail_type` |
| X12 | 1 番人気馬の馬齢 | 2 / 3 / 4 / 5 / 6 / 7+(集計後に分類) | dimension `horse_age` |
| X13 | 1 番人気馬の性別 | 牡 / 牝 / セン | dimension `horse_sex` |
| X14 | 1 番人気馬の乗り替わり(前走比) | あり / なし | dimension `is_jockey_change` |
| X15 | **1 番人気の単勝オッズの帯** | ≤1.9 / 2.0〜2.9 / 3.0〜3.9 / 4.0〜5.9 / ≥6.0 | filters `win_odds`(5 回) |
| X16 | **頭数(出走予定)の帯** | ≤9 / 10〜12 / 13〜15 / ≥16 | filters `scheduled_horse_count`(4 回) |
| C01 | 対照: 1 番人気馬が芦毛 | 芦毛 / 栗毛(主の family に入れない) | dimension `coat_color` |

- X15 は市場の情報そのもの(1 番人気が弱いと思われているほど崩れやすい)で、「当たり前」の水準が高い。他の材料が **X15 と X16 を足しても残るか**は見ない(層に入れられないため)。残った材料は「X15・X16 の言い換えではないか」を、報告で 1 番人気の平均オッズ(材料の水準ごと)を添えて読む。
- 馬場状態・天候は当日の値なので、**発走前に分かる材料としては発走の直前(当日朝〜)になる**ことを報告に書く。前日までは使えない。
- 出走馬の構成のうち、BASHIRA で 1 番人気の行に付けられる馬齢・性別・乗り替わり(X12〜X14)だけを入れる。他の馬の構成(例: 上位人気の拮抗)は X15 の言い換えになるので別立てにしない。
- 検定の数 m = 探索で **n ≥ 300(レース数)の水準の総数**(材料 X01〜X16 のうち)。水準が n < 300 のものは検定から外すが、表には残す。対照 C01 は family に入れず別枠。

## 5. 判断の目安(事前登録)
### 候補(探索の期間)
水準ごとに: (1) レース数 n ≥ 300、(2) |z| ≥ 3、(3) 両側 p を m 件で BH 補正した q < 0.05。
### 確認の期間(候補を固定してから 1 回だけ引く)
「残った」: (1) n ≥ 300、(2) 探索と同じ向き、(3) 同じ向きの片側 p を候補数 K で Holm 補正して < 0.05。
### 回収率(荒れやすさがオッズに織り込まれているか)
荒れやすい向き(`over`:A の率が期待より高い)で確認に残った水準 L について、**人気薄の帯**(4〜9 番人気・10 番人気以下)の単勝・複勝の回収率が、同じ人気順の層で L 以外より高いかを見る。
- 層は人気順(1〜18)。期待 E_s = n_{L,s} × (L 以外の同じ人気順の平均払戻)。z は L の層ごとの払戻の標準偏差(`stddev` を取る)から: Var = Σ n_s sd_s²。基準側の誤差は無視した近似(最大 √2 倍過大の可能性があるので、判断は z ≥ 2 でなく Holm 補正後 p < 0.05 かつ回収率の差の符号と大きさ(pt)で行う)。
- 検定は 候補(over)× 帯 2 × 券種 2(単勝・複勝)、片側(高いほう)、Holm。**判断は確認の期間だけ**で行い、探索の期間の値は向きの確認に使う。
- 参考に、L 以外の同じ帯の回収率と、L の平均オッズも出す。回収率が 1.0 を超えるか(買って儲かるか)は別に書く。
- 荒れやすさを S1(勝ち馬が 6 番人気以下)・S2 でも、残った水準について記述する(検定はしない。S1 は 2 群の比較の z を参考値として付ける)。

## 6. 取り方と上限
- 呼び出しは 1 本ずつ(並列にしない)。get_stats は全体で 60 回(180 回分)以内。見積もり: 探索 = ALL 1 + X01〜X14 の 14 + X15 の 5 + X16 の 4 + C01 の 1 + 候補の回収率用(`dimensions: [win_odds_rank]` 〈ALL 1 回 + 候補の材料ごと 1 回〉)最大 9 = 約 34。確認 = ALL(A)1 + 候補の材料(A)最大 8 + 回収率用 ALL 1 + 材料ごと最大 8 = 約 18。合計 約 52。超えそうなら候補の多い材料から先に確認し、足りない分は報告に書く。
- 回収率用の集計: filters は材料の水準を含める。dimensions `["win_odds_rank"]`(または材料 × 人気順の 2 次元)、metrics = 勝ち数・3着内数・単勝払戻の合計・複勝払戻の合計・同 stddev。
- `get_entries`・`get_races` で個票を引くことは(規約の網羅的取得を避けるため)しない。ただし、報告に出す実例(アルゼンチン共和国杯など)の確認のため 1〜2 レースだけ `get_races` を引くことはある(結論には使わない)。

## 7. あらかじめ分かっている限界
- A・S1・S2 は荒れの代理で、三連単の配当そのものではない。
- 芝ダを層に入れられない。クラスだけが層。
- 年ごとの変動(特に 2020 の無観客)は層に入れていない。
- 基準側の誤差を入れた z でも、同じ日・同じ場のレースは馬場・天候を共有するので独立ではない(日単位の相関を無視。z は過大の可能性)。
- 確定オッズ・確定人気で作った指標。発走前の分析の時点(約 30 分前)のオッズとは違う。特に X15 は確定オッズの帯。
- 「荒れやすい」が分かっても、オッズに織り込まれていれば回収率には効かない。§5 の回収率でそこまで見る。
