# #258 第1段: prior の頭数正規化を「乗算」から「ロジットシフト」に替えた前後比較

> **これは LLM を使わない prior の比較であって、ツール全体の確率の質ではない。** 実 Claude API は使っていない。
> LLM 補正量は #41 の subagent 近似(`docs/investigations/probability-quality-41-llm/`)で、本物ではない。
> 標本は #41 の 33 レース・429 頭(出走 8 頭以上)で、**Brier の差を有意に検出できる大きさではない**
> (「構造上の欠陥の除去」であって「当たり具合の改善」ではない、という前提で、悪化していないことを確かめるのが目的)。

## 何を替えたか
- 旧(〜#226): 各馬の raw を [0.02, 0.95] にクランプし、その合計が目標 `min(3, 頭数)` から ±10% を超えたときだけ、
  全馬に `目標 / 合計` を掛けていた(`normalizeTolerance = 0.1`)。
- 新(#258): 各馬の raw を [0.02, 0.95] に収めて logit に変え、**全馬に共通の c を足して**
  Σ clamp(sigmoid(logit_i + c), 0.02, 0.95) = 目標 となる c を二分法で求める(`normalizeFieldPriors`)。
  許容(ゲート)は撤去し、常に Σ=目標。
- 変えた理由: 「近走着順」の補正が全馬で平均プラスに偏る(素点の平均が中立値 0.33 を上回る)ため、raw の合計は目標を
  上回り、乗算の倍率は 1 より小さい。このため確率の広がり(sd)が raw の 0.77 倍に縮んでいた(#258 の調査コメント)。
- **ユーザー決定(2026-10-12)**: 確率の加算シフトは、下位の馬 25/429 頭を 0.02 の床に同値で潰す(穴馬を狙うツールに不向き)
  ため採用せず、**ロジットシフト**を採用した。

- `rawPrior` は、2026-10-11 に取り直した戦績(約 500 リクエスト・1.5 秒間隔)から `runAnalysis` と同じ手順で再計算した値で、
  **#226 の騎手の成績は入っていない**(騎手項は補正なし)。#258 は正規化だけを替えるので `rawPrior` は変わらない。

## 読み方と限界
1. **Brier は動かない**(旧 0.1661 → ロジットシフト 0.1662。差 +0.00012 で、区間は 0 をまたぐ)。想定どおり。
2. **広がりは部分的にしか戻らない。** ロジットでの広がり(オッズ比)は保たれるが、確率の sd は raw の 0.77 倍(旧)→
   0.86 倍(ロジットシフト)で、1.0 には戻らない。c が負のとき、確率の差は p(1−p) 倍に縮み、下位ほど縮むため。
   確率の差を保つ加算シフトは sd 比 1.000 になるが、床に 25 頭が同値で張り付く(旧・ロジットシフトは 4 頭・同値なし)。
3. **人気順ごとの平均 prior はほとんど動かない**(1 番人気 0.305 → 0.308、10 番人気以下 0.167 → 0.163)。
   prior の最大は 0.478 → 0.616 に上がる。人気順の表の平坦さは、順位(誰を上位に並べるか)の
   問題で、正規化では直らない。これは #258 の調査コメント(「平坦さの主因は広がりではなく順位」)と整合する。
4. **順位は変わらない**(レース内の馬対で大小が入れ替わった数は 0。市場との ρ の中央値も同じ 0.615)。
5. **#84 との相互作用(要注意・未解決)**: PL フィットの失敗が、旧では 0 件だったのに対し、ロジットシフトでは
   「窓の外に答える LLM」で ±0.10 が 1/19800・±0.15 が 1/19800 あった(加算シフトは 0/19800 と 1/19800)。
   - 失敗したのはいずれも同じレース(202606040911。prior の最大 0.616 の突出馬がいる 16 頭立て)で、LLM が
     その馬を +0.10(または +0.15)、他の多くを 0 にクリップした入力(Σp が 2.15・2.30、最大 0.716・0.766)。#84 の
     「断然人気馬の p が再スケール後に 1 に近づく」型と同じ機序と見られる。
   - **件数が 1〜2 件のため、旧との差は統計的に検出できない**(独立な標本は 33 レースで、疑似標本を増やしても増えない。
     prior のみ・実測の LLM 補正量では前後とも 0/33)。ただし、prior の最大が上がる以上、#84 の露出は旧より増える方向。
   - bench(`scripts/bench-joint-model.ts`)の合成分布での not-converged(N=3200、5 シード平均)は、旧 0.30%(default)/
     0.29%(wide15)に対し、ロジットシフト後は 0.26%/0.21%(シード間のばらつき 約 0.09pp の内)。この合成分布は
     突出馬(raw 0.9 以上)がいるレースが半数近くあり(`runModelLayer` の出力で default 46.0%・wide15 50.0%。
     実測の raw の最大は 0.833 の 1 頭)、実分布を代表しない。
   - 本番の尾部での再測定は、#266 の書き出し(保存済みの prior・contributions_json・adjusted_prob)が使えるようになってから行う。
6. **限界**: 騎手の成績(#226)なし。LLM 補正量は subagent 近似で、新しい prior に対する LLM の応答は測っていない。
   標本は 33 レース(中央 21・地方 12 のうち 8 頭以上)で、Brier の改善幅 0.002〜0.003 を検出するには足りない。
