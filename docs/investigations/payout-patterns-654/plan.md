## 3. 基準(単勝のオッズから見た公平な配当)
- 市場の勝率 q_i = (1/winOdds_i) / Σ_j (1/winOdds_j)(レース内で合計 1)。
- 人気順は q の降順の順位(`ninki` は使わない。同じ q は馬番の小さい方を上位にする)。
- 組合せの的中確率 p は Harville(Plackett–Luce の逐次抜き取り): 1→2→3 着の順で、残りの馬の q を割り戻して掛ける。
  - 馬単 (i→j): q_i · q_j/(1−q_i)。馬連 {i,j}: 両順序の和。三連単 (i→j→k): q_i · q_j/(1−q_i) · q_k/(1−q_i−q_j)。三連複 {i,j,k}: 6 順序の和。ワイド {i,j}: 3 着内に両方が入る確率 = Σ_{k≠i,j} (三連複 {i,j,k} の確率)。
- 公平な配当(100 円あたり)= 100 × (1−t) / p。控除率 t は JRA の券種別: 馬連・ワイド 22.5%、馬単・三連複 25%、三連単 27.5%(単勝・複勝 20%)。全体の水準(的中組合せの R·p/100 の平均が 1−t に近いか)で仮定の妥当性を見て、報告に書く。
- 副次の基準(Harville の癖の切り分け用): 2 着・3 着の確率を q^λ・q^μ で割り引く Lo–Bacon-Shone 型。λ・μ は**前半**の着順(1〜3 着)の最尤で当て、後半にもその値を使う。これは候補を作る道具ではなく、形の結果を「単勝からの式の癖」と「組合せの売上の偏り」に分けて読むための併記。
- 確定オッズは本番の分析の時点(発走の約 30 分前)より情報が多い。過去の結果には的中した組合せの配当しか無い(外れた組合せのオッズは分からない)。どちらも結論に書く。

## 4. 指標(形 F・期間について)
形 F は「レースごとに、買う組合せの集合」を決めるもの。F に属する組合せが 1 つもないレースは F の対象外。
- 対象レース数 N、買った組合せの総数 T(1 レースあたりの点数 T/N も報告に必ず書く)。
- 回収率 ROI = Σ(的中した F の組合せの配当) ÷ (T × 100)。
- 的中数: 実際 A = 的中した F の組合せの本数、見込み E = Σ_レース Σ_{c∈F} p(c)。比 A/E と z = (A−E)/√E(ポアソン近似)。
- 配当の比 = Σ_的中 R ÷ Σ_的中 (100(1−t)/p)(的中した組合せが Harville の公平配当に対して高かったか)。
- 感度: 配当の上位 1・3・5 件を除いたときの ROI。
- レース単位のブートストラップ(2,000 回・シード 654): ROI の 95% 区間(2.5・97.5 パーセンタイル)と、片側 p 値 = 「再標本の ROI が 1.0 以下になった割合」(H1: ROI > 1)。
- 高配当の出方(条件の指標): 万馬券(配当 ≥ 10,000 円)の的中の本数と、Harville の見込み Σ_{c: 100(1−t)/p(c) ≥ 10,000} p(c)。10 万円以上も同じ。

## 5. 探し方(前半だけ)
### A. 人気の形(form)
人気帯を 2 通り定める(前半の分布を見てから決めない。ここに書いた値で固定)。
- 順位帯 R: R1 = 1 番人気、R2 = 2〜3 番、R3 = 4〜6 番、R4 = 7〜10 番、R5 = 11 番以降。
- 勝率帯 Q: Q1 = q ≥ 0.30、Q2 = 0.15〜0.30、Q3 = 0.07〜0.15、Q4 = 0.03〜0.07、Q5 = q < 0.03。

形の族(帯の族ごと):
- 馬連・ワイド: 帯の非順序対 {X,Y}(15 ずつ)。
- 馬単: 帯の順序対 X→Y(25)。
- 三連複: 帯の多重集合 {X,Y,Z}(35)。
- 三連単: 1 着の帯 × {2 着, 3 着} の帯の非順序対(5 × 15 = 75)。
- 加えて帯によらない形: 上位 k 頭(k = 3,4,5,6)のボックス(馬連・馬単・三連複・三連単)、1 番人気を 1 着に固定して残りを全通り(馬単・三連単)、1 番人気を軸にした流し(馬連・ワイド・三連複)、全組合せ買い(5 券種。市場全体の偏りの基準)。

### B. レースの条件
頭数帯(≤8 / 9〜12 / 13〜15 / 16 / 17〜18)、クラス、重量の種別、芝ダ、距離帯(〜1400 / 1401〜1800 / 1801〜2200 / 2201〜)、馬場、季節(12〜2 / 3〜5 / 6〜8 / 9〜11)、競馬場、牝馬限定、重賞か、年齢の条件(2 歳 / 3 歳 / 3 歳以上。`raceData02Spans` から)、人気の割れ方(q の正規化エントロピー H/log(n) を前半の 3 分位で区分。境の値を後半にも使う)、1 番人気の q の帯(≥ 0.40 / 0.30〜0.40 / 0.20〜0.30 / < 0.20)。

条件ごと・券種ごとに「全組合せ買い」の ROI、的中組合せの配当の比、万馬券の本数の比(実際/見込み)を出す。

### C. 条件 × 形
多重比較を増やしすぎないため、A で候補になった形に限り、B の条件と掛け合わせる。

## 6. 候補の目安(前半)
- 形の ROI(族 F1): N ≥ 300、的中 A ≥ 30、ROI ≥ 1.05、ブートストラップ 95% 下限 > 0.90、上位 3 件を除いた ROI ≥ 0.95。
- 形の的中数の比(族 F2): A ≥ 30 かつ |z| ≥ 2(両向き。Harville の癖か売上の偏りかは、配当の比と併せて読む)。
- 条件の荒れやすさ(族 F3): N ≥ 200 で、「全組合せ買い」の ROI の 95% 下限 > (1−t)(市場の見積もりの外れが大きい条件)、または万馬券の本数の比 ≥ 1.3 かつ見込み ≥ 10 かつ z ≥ 2。
- 条件 × 形(族 F4): F1 と同じ目安。

候補は `candidates.json`(族・定義・前半の値)に書き出してコミットし、そのあと後半を開く。

## 7. 後半の判定(1 回だけ)
候補ごとに同じ指標を後半で出す。残るのは次をすべて満たすもの。
- 同じ向き(ROI の族は点推定 ≥ 1.00、比の族は同じ符号)。
- 多重比較: 族ごとに片側 p 値(ROI はブートストラップ、比は正規近似)に Benjamini–Hochberg を掛けて q < 0.10。Holm(α = 0.05)の結果も併記する。
- 感度: ROI の族は上位 3 件を除いても ≥ 0.95。
- 件数: 後半の N ≥ 150、的中 ≥ 15。

後半で条件を作り直さない。作り直したら新しい探索として扱い、そう書く。残らなかった候補の主なものも報告に書く。
