## 3. 脚質の判定(発走前に分かる範囲だけ。後知恵にしない)

  旧版 `classifyHorseLegStyle`(1 コーナーのみ)は検定に入れない。
- Python への移植(`scripts/pace-mismatch-683/legstyle.py`)は、同じ入力 3,000 件を TS 版(`xcheck_legstyle.mjs`、node の `--experimental-strip-types`)と突き合わせて 3,000 件一致を確認した。
- 過去走は**そのレースの日付より前**の走だけ(同じ日の別のレースも使わない)。材料は csv の走と hist 内の前の走を合わせる(raceId で重複除去)。通過順が空の走は数えない。

## 5. レース単位の材料
- **f = 前に行きたい割合 = (逃げ + 先行) ÷ 判定できた馬**。
- **人気の上位 = 1〜3 番人気**(確定の人気)の、判定できた馬。構成は (front 数, back 数)。front = 逃げ・先行、back = 差し・追込。
- **しきい値は 2 案**(探索の期間の対象 2,690 レースの f の分位点。結果を見ずに特徴量だけで決めた):

| 案 | 前に行きたい馬が少ない(f ≤) | 多い(f ≥) |
|---|---|---|
| T1 三分位 | 0.2667(下位 1/3 点) | 0.4000(上位 1/3 点) |
| T2 極端(20% / 80%) | 0.2000 | 0.4667 |

- **H1(前残り)の条件**: 人気上位に back が 2 頭以上、かつ f ≤ 下側のしきい値。**検定する群 = そのレースの前に行きたい馬(逃げ・先行)**。向き: 市場の見込みより 3着内が**多い**(O/E > 1)。
- **H2(差し決着)の条件**: 人気上位に front が 2 頭以上、かつ f ≥ 上側のしきい値。**検定する群 = そのレースの差し・追込の馬**。向き: 市場の見込みより 3着内が**多い**(O/E > 1)。
- 群を人気の帯で分ける: **1〜3 / 4〜9 / 10 番人気以下**(#665 と同じ)。
- **ユーザーの関心は穴なので、主の関心は 4〜9 と 10 以下の帯**。1〜3 の帯は検定の数には入れるが、解釈の中心にしない。全人気の合計は記述だけ(検定しない)。

## 6. 市場の見込みと指標
- q = (1/確定単勝オッズ)をレース内(取消・除外を除く、オッズのある馬)で割り戻した値。
- 3着内の見込み p3 = logistic(a + b·logit(q) + c·ln(頭数))(#656 と同じ形。頭数 = 取消・除外を除く出走頭数)。
- **案 B(主): 探索の期間の対象レースの全馬で (a, b, c) を最尤で当て直し(Newton 法)、確認の期間はその固定係数で見る。** 案 A(参考): 本番の #656 の固定係数 [2.857, 0.9216, −0.5561](確認の期間を含むデータで作られているので、確認の期間に有利な漏れがある)も併記する。
- 確定オッズは分析の時点(発走の約 45 分前)より情報が多い(本番より見込みが厳しい側に出る)ので、**報告に明記する**。
- 指標: 群の 3着内の実数 O と見込みの合計 E = Σp3 の比 **O/E**。z = (O − E) / √(Σ p3(1−p3))(馬ごとの独立なベルヌーイを仮定。同じレース内の馬は完全には独立でない近似であることを限界に書く)。両側 p は正規近似。
- 副の指標: 単勝・複勝の回収率(払戻はレースの `payouts`。同着の複勝は払戻の馬番で突き合わせる)。**検定の family には入れず**、候補になったものについて、同じ帯の「条件に当たらないレースの同じ脚質の馬」と並べて報告する(差の z は参考値)。

## 7. 検定の数、候補、確認の判断(事前登録)
- 検定 = H1・H2 × しきい値 2 案 × 人気の帯 3 = **12 が上限**。群の頭数が 300 頭未満のセルは検定から外し(表には残す)、残った数を m とする。12 を超えない。
- **候補(探索の期間)**: (1) 群の頭数 ≥ 300、(2) 両側 p を m 件で BH 補正した q < 0.05。向きは問わない(H の予想と逆でも、市場が買いすぎ・売りすぎている情報なので候補になる)。H の予想の向きかどうかは別に報告する。
- **確認の期間(候補を固定してから 1 回だけ)**: 「残った」= (1) 群の頭数 ≥ 300、(2) 探索と同じ向き、(3) 同じ向きの片側 p を候補数 K で Holm 補正して < 0.05。候補が 0 件なら、確認の期間は開かず、その旨を報告する。
- ハンデ戦(`weightType = ハンデ`、417 レース前後)は検定せず、候補のセルについて、ハンデ戦と非ハンデ戦に分けた O/E と頭数を記述するだけ(#682 でハンデ戦は荒れやすいと出ているため、混ざりの確認)。

## 8. 対照(2 つ)
1. **レース内の補集合(一貫性の確認)**: 各セルで、同じレース・同じ人気の帯の**反対の脚質の群**の O/E と z も出す。3着内の総数は固定なので、群が見込みより多ければ補集合は少なく出るはず。独立した検証ではなく、計算の取り違えがないかの確認。
2. **レース内シャッフルの帰無分布**: 対象レースごとに、判定済みの馬の脚質ラベルを**レース内で並べ替え**(不明の馬は動かさない)、条件の判定から群の作成までやり直し、12 セルの max|z|(群の頭数が観測と同じ 300 頭以上のセルのみ)を記録する。**1,000 回、`random.Random(683)` の seed 固定**。観測の max|z| がこの帰無の 95 パーセンタイルを超えるか、経験的な p(= 帰無の max|z| が観測以上の割合)を報告する。人気・結果・見込みは動かさない。
