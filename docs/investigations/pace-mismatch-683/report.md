読み方:
- **H1(前残り)は、穴の帯で出ていない。** 4〜9 番人気の前に行ける馬の O/E は 0.965(T1)と 1.030(T2)で、符号も揃わず、z は ±0.5 以内。10 番人気以下は頭数が 266 と 133 で、標準誤差が 25〜36% なので何も言えない。
- **H2(差し決着)は、4〜9 番人気で O/E が 1.04〜1.07 と予想の向きだが、有意ではない**(最大 z +1.59、q 0.60)。10 番人気以下は逆向き(0.84〜0.89、z −1.2)で、予想と合わない。標準誤差は 4〜9 番人気で 4.5〜6%、10 以下で 9〜13% なので、**±12% 程度より小さい効果は、この探索の頭数では見分けられない。**
- シャッフルの帰無(1,000 回、seed 683)で、観測の max|z| = 1.59 に対し、帰無の中央値は 1.61、95 パーセンタイルは 2.65。経験的な p は 0.514。**観測の最大値は、脚質ラベルをレース内でシャッフルしたときにふつうに出る範囲に収まる。**
- 補集合(反対の脚質の群)の O/E は、群と概ね反対向きかほぼ 1 で、計算の取り違えは見られない。ただし 3着内の総数が固定されるのは全人気の合計だけなので、人気の帯ごとの補集合は「鏡」にはならない(例 H2|T1|10 以下は群 0.888・補集合 1.058)。

## 3. Issue の問いへの答え
- **H1・H2 のそれぞれで残ったか**: 残っていない(候補 0 件のため確認は未開封)。H2 の 4〜9 番人気に弱い正の傾向があるが、探索の期間でも有意でなく、「見つかった」とは言えない。
- **回収率(単勝・複勝)に効くか**: 候補が無いので計算していない(計画で候補についてのみ出す約束)。O/E が 1.07 の群でも、控除を超えるほどの水準かは別問題で、この結果から回収率の改善は主張できない。
- **ハンデ戦(#682)と分けても残るか**: 残る対象が無いので分割していない。
- **本番に使うならどの形か**: 今回の結果では、確率の補正・見送りのルール・LLM への材料のいずれも、新しく足す根拠は得られなかった。**市場はこの種の展開の構成(人気上位の脚質×前に行きたい馬の割合)を、本番の脚質の定義の粒度では、概ね織り込んでいる**。#653・#665 の馬単位の結論(市場の織り込み)と整合する。
- 後知恵で説明できる「荒れたレース」を、発走前の特徴で選別できる、という見立ては、この定義・この期間では支持されなかった。

## 4. 限界(結果の解釈に効くもの)
1. **データが短い**。2 年強(探索 2,690 レース)で、Issue の 2016〜 は取れなかった。標準誤差が 4〜13% あり、「効果が無い」ではなく「±10% 規模の効果は見えない」が正確な言い方。
2. 探索の期間は先頭が左端で打ち切られ、判定率の除外が多い(481 対 31)。ベテラン寄りに偏る。
3. 確定オッズは分析の時点(発走の約 45 分前)より情報が多く、見込みが本番より鋭い。市場の織り込みを過大評価している可能性があり、本番の見込み(#656)ではもう少し差が出る余地がある。
4. 脚質は前走までの通過順の粗い 4 分類。距離・コース替わりで意味が揺れる。人気の上位は確定の人気で、1〜3 番人気に限った。
5. z は馬ごとの独立を仮定した近似。同じレースの馬は負の相関なので、実際の誤差は多少小さい側にずれうる。
6. 検定は 12 セル(うち 8 を検定)。事前登録の基準が厳しい(BH q < 0.05)ので、中程度の効果は拾わない設計。
