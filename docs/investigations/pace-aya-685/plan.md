## 2. 仮説(#684 の H5 と完全に同じ定義)
- レースの条件: 確定の人気 1〜K 番人気の馬のうち、脚質が判定できた馬に**逃げ・先行が 1 頭もいない**。かつ、判定できた馬が K=3 で 2 頭以上、K=5 で 3 頭以上(#684 §4b と同じ下限)。
- 群: そのレースの逃げ・先行の馬(脚質は `analyzeHorseLegStyle` の style の移植 = `scripts/pace-mismatch-683/legstyle.py`)。**ハナ候補の定義は使わない。前に行く馬の割合 f も条件にしない。**
- 予想: 群の O/E > 1(3着内に、市場の見込みより多く来る)。
- セル: K = 3 と 5、人気の帯は 4〜9 と 10 以下(1〜3 は条件上、群が空か小さいので外す)。**2 × 2 = 4 セル**。
- 検定: 各セルの片側 p(予想の向き)を 4 セルで Holm 補正。**片側 p(Holm 後)< 0.05 かつ O/E > 1 を「残った」とする。頭数による足切りはしない**(4 セルとも検定する。頭数が小さければ z が自然に小さくなり、p が効かない)。群が空のセルは p = 1 として数える。

## 4. 市場の見込み(#683 の案 B を固定で使う)
- q = (1/確定単勝オッズ)をレース内で割り戻した値。3着内の見込み p3 = logistic(a + b·logit(q) + c·ln(頭数))。
- **係数は #683 の案 B を固定**: (a, b, c) = [2.6574, 0.8926, −0.5093](探索の期間 2024-08〜2025-08 で当て直した値。`docs/investigations/pace-mismatch-683/candidates.json` の `coef_B` を読む。コードでこの値との一致を確かめる)。**今回のデータで当て直した係数は検定に使わない。**
- 参考: 今回の期間で当て直した係数(`a683.fit_logit`)での O/E・z も出す(検定しない)。
- 較正: 対象レースの全馬の O(3着内の実数)と E(Σp3)を、固定係数・当て直し係数の両方で報告する。
- 確定オッズは分析の時点(発走の約 45 分前)より情報が多いので、市場の見込みは本番より鋭い。報告に明記する。
