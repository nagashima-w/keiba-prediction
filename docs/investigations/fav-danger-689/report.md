# #689 報告: 単勝 1.0〜2.9 倍の 1 番人気が 3着内を外すレースを、発走前の材料で見分けられるか

**結論(先に): 見分けられなかった。** 計画どおり、p̂ が低い側の 3 分の 1(危ない側)の 1 番人気の 3着内の O/E は 1.004(n 1,743、z +0.21)で、予想した O/E < 1 の向きに出なかった。family の 4 セルは Holm 補正後にどれも残らない(補正後 p はすべて 1.0)。q(市場の見込み)だけで同じ割合を選んだ基準も O/E 1.006 で、モデルは基準と差がない。回収率(記述)では、危ない側で 1 番人気を外した 3 連複のボックスが 75.2%、全対象レースでは 65.9% で、数字の上では差があるが、後述のとおり選び方の良し悪しとは別と読む(推測)。

## 4. 回収率(記述。検定しない。100 円あたり)
1 番人気を外したボックス: (i) 2〜6 番人気の 3 連複(C(k,3) 点)、(ii) 2〜4 番人気のワイド(C(k,2) 点)。

| | 3 連複 2〜6 番人気 | ワイド 2〜4 番人気 |
|---|---|---|
| 危ない側(1,743 レース) | 75.2%(的中 204 レース) | 80.2%(615) |
| q だけの基準(1,856) | 70.4%(240) | 82.9%(723) |
| 危ない側でない(3,777) | 61.5%(372) | 80.2%(1,512) |
| すべての対象(5,520) | 65.9%(576) | 80.2%(2,127) |

- 危ない側は、危ない側でないレースより 3 連複が高い(75.2% 対 61.5%)が、**q だけの基準でも 70.4%** あり、2.0〜2.9 倍の 1 番人気は断然でない分、配当の高い組が出やすい、という構成の差の可能性が高い(推測。1 番人気を外した 2〜6 番人気のボックスの的中率だけでなく払戻の裾の重さにも依存し、標準誤差は推定していない)。ワイドは差がほとんどない。**どちらも 100% に届かない。**
- 1 番人気が実際に 3着内を外したレースだけで買えるわけではない(発走前には分からない)。ここでの回収率は、点が低い側のレースを全部買った場合の値。

## 5. 限界
1. **確定オッズ**を使った(分析の時点〈発走の約 45 分前〉より情報が多く、市場の見込みが鋭い側)。効果は小さく出る側。
2. 帯 1.0〜1.9 のセルが成立しなかった(危ない側に 3 頭)。**1.0〜1.9 倍の 1 番人気の中で危ない度を見分ける**という問いには、この計画の「全体の下から 3 分の 1」では答えられていない。帯ごとにしきい値を引き直す案は、結果を見たあとの変更になるので、行っていない。
3. z は 1 レース 1 頭の独立の近似。履歴は hist の 2021-06-20 以降だけ(探索の初めは騎手・調教師の窓が短い)。
4. 期間は #683〜#688 で別の仮説に使用済み(計画 §2)。
5. 材料の寄与は小さい(対数損失で約 0.2%、較正だけの Mc に対する差は M0 → Mc の差と同じ桁)。真の差が小さいのか材料が粗いのかは区別できない。
6. 「残った」と「儲かる」は別。回収率は 100% 未満。
