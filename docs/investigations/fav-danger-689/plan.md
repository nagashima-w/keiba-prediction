## 3. 対象・市場の見込み・材料
- **対象 = 対象レースの 1 番人気(確定の人気 1、単勝オッズあり)で、単勝オッズ 1.0〜2.9 倍の馬**。帯は 1.0〜1.9 と 2.0〜2.9。
- q = 確定単勝オッズの逆数をレース内(取消・除外を除く、オッズのある馬)で割り戻した値。p3 = logistic(2.6673 + 0.9162·logit(q) − 0.4918·ln(頭数))(#687 の `prep-results.json` の `coef`、固定)。**この式は 6 番人気以下を含む全馬で当てた係数で、1 番人気への当てはまりは未確認**。1 番人気の p3 が高い側/低い側に偏るかは、切片と logit q の係数が学習する(Mc に含める)。
- 勝ちの市場の見込み = q。
- 材料(すべてそのレースより前に分かるもの。作り方は #688 と同じ):
  1. **logit q**(探索の対象馬の平均を引き、標準偏差で割る)。
  2. **#653 の 4 印**(休み明け・芝ダ替わり・前走で逃げた・人気薄の大敗続き)と**前走なし**。人気薄の大敗続きは 1 番人気ではほぼ 0 になる見込み(q < 0.05 が条件)で、材料として弱い。印が null は 0。
  3. **ハンデ戦**。
  4. **騎手の差・調教師の差**(#642 の式。そのレースの日付より前の走だけ。730 日の窓。標準化)。
  5. **脚質の旗**(前・後ろ)、**g(#687 の展開の予想)との積**、**「先行に人気が集まったレースの差し・追込」**、**芝**、**距離の対数**。
  6. **レースの条件(#682 で荒れやすかった条件)**: 16 頭以上、小倉と福島、1 番人気が牝馬。
  7. **2 番人気のオッズとの差** = ln(2 番人気のオッズ) − ln(1 番人気のオッズ)(標準化)。大きいほど断然。
- 使わないもの: #687 の馬ごとの向き不向き D(再現性 0.014)、競馬場そのもの(小倉・福島の旗のみ)。

## 4. 点の作り方
- 目的 = 対象馬の 3着内(y)。**ロジスティック回帰(L2)で、offset = logit(p3) を固定し、特徴量の係数 β だけを学習**する。切片は罰則なし。標準化は連続の特徴量だけ。
- **集合(5 個)**: **Mc**(logit q のみ + 切片。較正だけ動かす)、**M1**(logit q・休み明け・芝ダ替わり・前走で逃げた・人気薄の大敗続き・前走なし・ハンデ。7 個)、**M2**(M1 + 騎手の差・調教師の差・前の旗・後ろの旗・前の旗×g・後ろの旗×g・先行に人気が集まったレースの差し・追込・芝・距離の対数。16 個)、**M1c**(M1 + 16 頭以上・小倉と福島・牝馬・2 番人気との差。11 個)、**M2c**(M2 + 同じ 4 個。20 個)。#688 の M1 から 10 番人気以下の旗を除いたのは、対象が 1 番人気だけのため。**M0 = offset のみ**(p3 そのまま)。
- λ ∈ {1, 10, 100, 1000}。
- **選び方(探索の期間の中だけ)**: 半年ごとの 4 ブロック(2022-01〜06、2022-07〜12、2023-01〜06、2023-07〜12)で 1 ブロックずつ保持し、残り 3 ブロックで学習して保持ブロックの対数損失を出す。{Mc, M1, M2, M1c, M2c} × λ のうち 4 ブロックの平均が最小のものを選ぶ(同点なら材料の少ない集合)。
- **確認を開く条件(固定)**: 選ばれた集合が **M1・M2・M1c・M2c のいずれか**で、保持ブロックの対数損失が **M0 より小さいブロックが 4 つ中 3 つ以上**、かつ **Mc の最良の λ より小さいブロックが 4 つ中 3 つ以上**。満たさなければ**確認の期間を開かず**、そう報告する。
- 満たしたら、選んだ集合と λ を探索全体で学習し直し、**しきい値 t = 探索の対象馬の p̂ の下から 3 分の 1(1/3 分位点。p̂ は学習し直したモデルを探索の対象馬に当てた値〈当てはめ内〉)**と、**q のしきい値 tq = 探索の対象馬の q の下から 3 分の 1** を決め、`scores-coef.json`(特徴量・平均・標準偏差・β・λ・集合・offset の係数・t・tq)を**コミットしてから**確認の期間を 1 回だけ集計する。確認の期間での再学習・しきい値の再決定はしない。

## 5. 評価(確認の期間、1 回だけ)
- **危ない側 = p̂ < t の 1 番人気**(p̂ が低い = 3着内に来にくい)。予想は「危ない側の 3着内の O/E < 1」。
- **O/E** = 実数 O ÷ 期待 E。3着内の E は p3(固定係数)の合計、勝ちの E は q の合計。z = (O − E)/√Σp(1−p)(1 レース 1 頭なので独立の近似)。
- **検定の family(4 セル、片側 O/E < 1、Holm、α = 0.05)**:
  1. 危ない側(全体、1.0〜2.9)の 3着内。
  2. 危ない側のうち 1.0〜1.9 倍の 3着内。
  3. 危ない側のうち 2.0〜2.9 倍の 3着内。
  4. 危ない側(全体)の勝ち。
  - 帯のセルは全体と同じ t を使う(帯ごとに t を引き直さない)。「残った」= 3着内のセルは件数が 300 以上、かつ Holm 補正後の片側 p < 0.05。**1.0〜1.9 倍の危ない側が 300 に満たなければ、そのセルは p を報告するが「残った」とは判定しない**(件数不足と報告する)。セル 4 も件数 300 以上を要する。
- **基準(q だけで選ぶ)**: q < tq の 1 番人気(同じ割合を、q の順位だけで選んだもの)。同じ 4 セルを並べる(検定はしない)。選んだ割合も両方並べる。**p3 の 1 番人気への較正が全体として偏っていると、O/E < 1 は材料と無関係に出る**ので、(a) 対象馬全体の O/E、(b) 基準の O/E を必ず並べ、結論は「基準を下回るか」で書く。
- **記述(検定しない)**: p̂ の上側 3 分の 1(安全側)の O/E、中の 3 分の 1。帯別の件数。前半(〜2024-08-04)と後半(2024-08-05〜)。ハンデ戦と非ハンデ戦。探索の保持ブロックの O/E(当てはめの記述)。
- **回収率(検定しない。100 円あたり)**: 1 番人気を外した買い方を 2 つ固定する。(i) 2〜6 番人気(確定の人気 2 以上 6 以下の馬、頭数 k)の**ボックスの 3 連複**(C(k,3) 点、各 100 円)。(ii) 2〜4 番人気の**ボックスのワイド**(C(k,2) 点、各 100 円)。払戻は各レースの `payouts` から馬番の組合せで突き合わせる(同着で組が複数ある)。**危ない側のレース、基準の危ない側のレース、すべての対象レース**の 3 つで並べる。差の z は出さない(払戻の裾が重い)。
- **対照**: 確認の期間の対象の 1 番人気の間で p̂ を並べ替え(`random.Random(689)`、1,000 回)、同じ t で危ない側を選び直して、セル 1〜4 の「−z」の最大の帰無を作る。観測の最大の −z と、帰無の 95 パーセンタイル・経験的 p を報告する。
- **限界として必ず書く**: 確定オッズ(発走の約 45 分前の分析時点より情報が多く、見込みが鋭い側)。z の独立の近似。履歴は hist の 2021-06-20 以降だけ。期間の使用済み。確かめていない推測は推測と書く。「残った」と「儲かる」は別。

## 6. 検出力の目安
確認の期間の対象は 5,520 頭。危ない側は約 3 分の 1(約 1,800 頭)、3着内の確率は 0.8 前後で O の標準偏差は約 17(O/E で約 1.2% 程度の標準誤差)。1.0〜1.9 倍の危ない側は件数が少なく、300 に届かない可能性がある(結果を見る前の見積もりで、確認していない)。
