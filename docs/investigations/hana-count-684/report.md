## 4. Issue の問いへの答え
- **H3・H4・H5 は残ったか**: 探索の期間で候補が出なかったので、確認では開いていない。**H4b の 4〜9 番人気(O/E 1.05〜1.09)と H3b の穴(1.05〜1.10)に弱い予想どおりの傾向はあるが、有意でなく、シャッフルの帰無の範囲内。**
- **#683 の持ち越しは残ったか**: 残らなかった(Holm 後 p 0.114)。
- **回収率**: 持ち越しのセルのみ。単勝 0.794・複勝 0.767で、比較先と有意な差なし。
- **本番に使うならどの形か**: 今回の結果では、確率の補正・見送り・LLM への材料のいずれも、新しく足す根拠は得られなかった。ハナ候補の数という、脚質より細かい材料を足しても、市場は(本番の脚質より少なくとも確定オッズの時点では)織り込んでいる。#683 と整合する。

## 5. 限界
1. データが短い(探索 2,690・確認 3,355 レース)。標準誤差が 4〜13% あり、「効果が無い」ではなく「±10% 規模の効果は見えない」。群が小さいセル(H3a の穴・H5)は、検定そのものができなかった。
2. 確定オッズは分析の時点(発走の約 45 分前)より情報が多く、市場の見込みが本番より鋭い。
3. 短距離では最初に記録のあるコーナーが 3 コーナーになり、ハナ候補の意味が距離で揺れる(距離ごとの分割はしていない)。D1 は前走 1 走だけの情報でノイズが大きい。D2 は緩く、ほとんどのレースで N ≥ 3 になり、H3 の群がほぼ空になる(定義の帰結で、計画どおり変えていない)。
4. 脚質は前走までの通過順の粗い 4 分類。探索の期間は先頭が左端で打ち切られ、ベテラン寄りの偏りがある(#683 §4)。
5. z は馬の独立を仮定した近似。D1 と D2、H4a と H4b は同じ馬・レースを共有し、セルは独立でない。
6. H5 の下限(判定済み 2 頭・3 頭以上)は計画で私が決めた。ほかの下限では結果が変わりうる(検証していない)。
7. 「残った」と「儲かる」は別。
