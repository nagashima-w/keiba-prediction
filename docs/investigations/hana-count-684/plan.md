## 3. ハナ候補の定義(2 案。そのレースの日付より前の走だけ。通過順は各走の最初に記録のあるコーナー passing[0])
過去走の集め方は #683 と同じ(csv と hist を raceId で重複除去、同日を含めない、通過順が空の走は数えない)。
- **D1**: 前走(通過順のある直近の走)で passing[0] = 1。
- **D2**: 直近 3 走(通過順のある走)のうち、passing[0] ≤ 2 が 1 回以上。
- 通過順のある過去走が 0 本の馬は、どちらも「不明」(ハナ候補ではなく、脚質も不明)。脚質が不明の馬は #683 と同じく群に入れない。
- **N = そのレースの出走馬(取消・除外を除く)のうちハナ候補の頭数**(定義ごとに数える)。
- 注意: 短距離ではレースの最初に記録のあるコーナーが 3 コーナーになる(passing[0] は 3 コーナーの順位)。その走では「最初のコーナー」の意味が距離で揺れる。限界として報告に書く。検定には使わない。
- D2 は D1 を含む(D1 ⇒ D2)。N が D2 のほうが大きくなるため、N ≤ 1 や N = 1 のレースは D2 でごく少ない(`feature-counts.txt`: D2 の N ≤ 1 は 314 レース、D1 は 2,003 レース)。これは定義の帰結であり、変えない。

## 4. 群と仮説(人気の帯 1〜3 / 4〜9 / 10 以下は確定の人気で分ける。主の関心は 4〜9 と 10 以下)
群は、脚質が判定できて、確定の人気と単勝オッズがある馬だけ。
| 仮説 | レースの条件 | 検定する群 | 予想 |
|---|---|---|---|
| H3a 単騎逃げ | N = 1 | そのレースのハナ候補の馬(1 頭) | O/E > 1 |
| H3b 前残り | N ≤ 1(0 または 1) | ハナ候補でなく、脚質が「先行」の馬(脚質は #683 と同じ `analyzeHorseLegStyle` の style の移植。「逃げ」脚質でハナ候補でない馬は、どの群にも入れない) | O/E > 1 |
| H4a ハナ争い | N ≥ 3 | そのレースのハナ候補の馬 | O/E < 1 |
| H4b ハイペース | N ≥ 3 | 脚質が「差し」「追込」の馬(ハナ候補かどうかは問わない。H4a と同じ馬が重なりうる) | O/E > 1 |
- H3a・H3b・H4a・H4b の 4 仮説 × 定義 2 × 帯 3 = **24 セル**(H5 の 4 セルは §4b。全体は 28)。**検定するのは群の頭数が 300 以上のセルだけ**(表には全セルを残す)。検定する数を m とする(`explore-results.json` の `m_tested`。事前に分かっているのは上限 24 だけ)。
- 参考として、探索の期間の群の頭数は `feature-counts.txt` にある。それによれば D2 の H3a・H3b は全帯で 300 頭未満、D1 の H3a(10 以下)・H4a(1〜3 と 10 以下)・H4b(1〜3)も 300 頭未満になる(D2 の H4a・H4b は全帯で 300 頭以上)。検定に回るセルが少ないのは、この規則の帰結であり、規則は変えない。
- (H5 を除き)H4a の予想だけが「市場より来ない」(O/E < 1)。他の 3 つは O/E > 1。

### 4b. 仮説 H5(人気上位がそろって差し。前に行く馬が人気薄)— 2026-11-08 の追加(コーディネーターの指示。集計の前に計画へ入れる)
| 仮説 | レースの条件 | 検定する群 | 予想 |
|---|---|---|---|
| H5 | 1〜K 番人気(確定の人気)のうち、脚質が判定できた馬に逃げ・先行が 1 頭もいない | そのレースの逃げ・先行の馬(脚質は #683 と同じ `analyzeHorseLegStyle` の style。ハナ候補の定義は使わない) | O/E > 1 |
- **K は 3 と 5 の 2 案**。人気の帯は **4〜9 と 10 以下の 2 つ**(1〜3 は条件上、群が空か小さいので外す)。2 案 × 2 帯 = **4 セル**。§4 の 24 セルと合わせて **28 セル**。検定は頭数 300 以上のセルだけで、BH の family は同じ(m は両方を合わせた数)。
- 条件の補足(計画で固定する私の読み): 条件を「脚質が判定できた馬が多い」レースに限るため、1〜K 番人気のうち判定済みが **K=3 で 2 頭以上、K=5 で 3 頭以上**(過半)あることを必須にする。判定済みが少ないレースでは「逃げ・先行がいない」が確かめられないため。この下限は結果を見る前に決めた。
- #683 の H1 との違い: H1 は「前に行きたい馬の割合 f が低い」も条件にしていた。**H5 は f を条件にしない**(前に行く馬の数はふつうでも、それがみな人気薄のレース)。
- 理由: 2026-11-08 のアルゼンチン共和国杯は、1〜8 番人気が差し・追込だけで、逃げ・先行はみな 9 番人気以下だった。1 コーナーで前にいた 6 頭のうち 5 頭が 1〜5 着に入った(9〜16 番人気)。前に行く馬の割合は 6/18 = 0.33 で、#683 の H1 の f の条件には入らないレースだった。**1 レースの観察から立てた仮説で、探索・確認の期間のデータは見ていない**(このレースは確認の期間の外〈2026-11-01 まで〉)。
- 補集合(対照)= 同じレース条件・同じ人気の帯で、群に入らない判定済みの馬(差し・追込)。シャッフルは §5 と同じ(組をレース内で並べ替え、条件を作り直す)。
- 参考の件数(`feature-counts.txt`): 条件に当たるレースは K=3 で 374、K=5 で 162。群の頭数は K=3 が 4〜9 で 681・10 以下で 284、K=5 が 4〜9 で 167・10 以下で 103。規則どおり検定に回るのは K=3 の 4〜9 だけになる見込み(規則は変えない)。
- 探索の候補・確認・回収率・ハンデ戦の扱いは §6 と同じ(H5 の予想の向きは O/E > 1)。

## 5. 市場の見込み・指標・対照(#683 と同じ)
- q = (1/確定単勝オッズ)をレース内で割り戻した値。3着内の見込み p3 = logistic(a + b·logit(q) + c·ln(頭数))。
- **案 B(主)**: 探索の期間の対象レースの全馬で (a, b, c) を最尤で当て直し(Newton 法)、確認の期間はその固定係数で見る。係数は #683 と同じ対象・同じ手順なので #683 の `candidates.json` の `coef_B` と一致するはず(一致を確認する)。案 A(本番 #656 の固定係数 [2.857, 0.9216, −0.5561])は参考に併記。
- 指標: O/E(O = 群の 3着内の実数、E = Σp3)、z = (O − E)/√Σp3(1−p3)、両側 p は正規近似。
- 副の指標: 単勝・複勝の回収率(払戻はレースの `payouts`)。**検定の family には入れない**。確認の期間の候補についてだけ出す(§7)。
- 確定オッズは分析の時点(発走の約 45 分前)より情報が多いので、市場の見込みは本番より鋭い。報告に明記する。
- **対照**: (1) 同じレース・同じ人気の帯の補集合の O/E・z(計算の取り違えの確認。補集合 = 同じレース条件・同じ人気の帯で、群に入らない判定済みの馬)。(2) **レース内シャッフル**: 対象レースごとに、判定済みの馬の (脚質, d1, d2) の組を**まとめて**レース内で並べ替え(不明の馬は動かさない)、N の計算から群の作成までやり直し、検定したセルの max|z| を記録。**1,000 回、`random.Random(684)`**。観測の max|z| が帰無の 95 パーセンタイルを超えるか、経験的な p(帰無の max|z| ≥ 観測)を報告する。人気・結果・見込みは動かさない。N は組を動かしても変わらない(同じレースの中の並べ替えのため)。

## 6. 候補、持ち越し、確認の判断(事前登録)
- **探索の候補**: (1) 群の頭数 ≥ 300、(2) 両側 p を m 件で BH 補正した q < 0.05、(3) 効果の向きが**その仮説の予想の向き**(H3a・H3b・H4b は O/E > 1、H4a は O/E < 1)。予想と逆向きは候補にしない(#683 は向きを問わなかったが、本 Issue は仮説ごとに向きが決まっているので、予想の向きだけにする。逆向きだったセルは報告に記述する)。
- **#683 からの持ち越し(探索の結果にかかわらず候補に入れる。1 セル)**: **H2|T1|4〜9 番人気**(#683 の定義そのまま: 人気上位 1〜3 番人気に差し・追込でなく逃げ・先行が 2 頭以上、かつ f = 前に行きたい割合 ≥ 0.4000。群 = そのレースの差し・追込の馬、予想 O/E > 1)。`candidates.json` に「持ち越し」と印を付ける。**この 1 セルは探索の期間をもう一度集計せず、#683 の値(n = 1,985、O/E 1.071、z +1.59)を引用するだけ。** この 1 セルは BH の m に含めない。
- **確認**: 候補(持ち越しを含む)を確認の期間で**1 回だけ**集計する。候補が持ち越しの 1 つだけでも開く。「残った」= (1) 群の頭数 ≥ 300、(2) 予想の向き、(3) 予想の向きの片側 p を候補数 K で Holm 補正して < 0.05。
- **回収率**(単勝・複勝): 確認の期間の候補についてだけ、副の指標として出す。比較先は「同じ脚質の群(定義は §4 の群)の、同じ人気の帯で、レースの条件に当たらないレースの馬」。差の z は参考値。検定の family には入れない。
- ハンデ戦(`weightType = ハンデ`)は検定せず、候補のセルについて、ハンデ戦と非ハンデ戦に分けた O/E と頭数を記述するだけ。
