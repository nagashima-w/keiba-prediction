## 結論
**5 セルのどれも「残らなかった」**(補正後 p < 0.05 かつ O/E > 1 を満たすセルが 0)。主の型 H6 の 4 セルは、4〜9 番人気の K=3 だけが O/E 1.037 と 1 を少し上回り、ほかの 3 セルは 1 を下回った。持ち越しの H2|T1|4〜9 は O/E 1.0545、片側 p 0.0124、Holm 後 p 0.062 で、わずかに届かなかった。

## 1. 対象
- 期間 2021-06-20〜2024-08-04 の表 10,801 レースのうち、除外は 障害 392・新馬 956・頭数<8 181・判定率<0.7 553 で、対象は 8,719 レース。(10,801 = 392+956+181+553+8,719)
- 左端の打ち切り: 判定率<0.7 で落ちたのは、2021-06 が 64/74、2021-07 が 207/288、2021-08 が 119/288、2021-09 が 48/240、2021-10 が 38/336、2021-11 が 3/264。2021-06 の対象は 0 レース。
- 条件に当たった対象レース数: H6 の K=3 が 1,263、K=5 が 306、H2|T1 が 2,315。
- 較正(固定係数): 121,739 頭で O 26,174、E 26,209.19(O/E 0.9987)。

## 6. 限界

- 左端の打ち切りでベテラン寄りに偏る。
- 期間のデータは #685 の 4 セルでも使っている。H6 は H5 の裏返しだが、問いは別。
- 並べ替えの帰無は 5 セルの max z を使う。計画どおり固定係数を使い、並べ替えは脚質ラベルだけ(f は動かさない)。
- 「残った」と「儲かる」は別で、回収率は上のとおり 1 に届かない。
- `__pycache__` は残していない。md は yomiyasu で推敲していない(必要ならメインが判断してほしい)。
