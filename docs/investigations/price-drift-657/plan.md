# #657-0 買い目の馬のオッズが、分析の後に下がっていないか(計画。結果を見る前に固定)

本番のコードは変えない分析。材料は配分の書き出し(545 行に配分の記録)。

## 指標の経緯
Issue のコメントは「見込みの的中と実際のずれ(#656 の 1.73 倍)のうちオッズの動きが占める分」を見るとしていたが誤りだった。見込みの的中(Σ ev÷odds = Σ 確率)はオッズに依らない。オッズの動きが効くのは「見込みの払戻(Σ 賭け金 × 確率 × オッズ)と実際の払戻のずれ」。そこで下のとおりに直した(Issue のコメントの直しはメインが行う)。

## 定義
- 確率 p = ev ÷ odds(買い目ごと)。賭け金 s。返還・判定不能の買い目は期待にも実際にも入れない。
- 分析時点の見込みの払戻 E0 = Σ s·p·odds。確定オッズでの見込みの払戻 E1 = Σ s·p·odds_final。実際の払戻 A。
- ずれ A/E0 を、A/E0 = (E1/E0) × (A/E1) に分ける。E1/E0 がオッズの動きの分、A/E1 が確率の見積もりのずれの分。対数でも同じ分解になる。

## 1. 馬ごとの比 r = 確定単勝 ÷ 分析時点の単勝
- 全馬(両方の単勝が有限で正、取消でない)。「買い目に入った馬」= いずれかの買い目(単勝・複勝・組合せの馬番。枠連は枠番なので除く)に含まれる馬。入らなかった馬と、分位点(10/25/50/75/90)・平均・N を比べる。
- 券種別(その券種の買い目に入った馬)、人気帯別(分析時点の単勝人気 1-3/4-6/7-)。
- 比の中央値の差には、並べ替え検定(行ごとに買い目の有無の割り当てを入れ替え)ではなく、レースを単位にしたブートストラップの 95% 区間を付ける。

## 2. 買い目ごとの確定オッズ
- 単勝: 全買い目で確定オッズ(result.horses[].win_odds)。
- 複勝・組合せ: 確定オッズは書き出しに無い。(a) 的中した買い目だけ、払戻 ÷ 100 を確定オッズとみなして実測する(複勝の bet.odds は下限なので、払戻との比は下限と実の幅を含む)。(b) 全買い目を、馬ごとの単勝の比の積(複勝は 1 頭の比)で動かす感度試算(実測ではない)。
- (a) の限界: 的中した組だけ見るので、勝った馬・来た馬のオッズの動きに偏る(選択の偏り)。外れた組は不明。

## 3. 分解
券種別・全体で E0・E1(単勝は実測、複勝・組合せは (b))・A・A/E0・E1/E0・A/E1 を出す。区間はレース単位のブートストラップ(2000 回、固定乱数)。

## 4. 締め切り直前
D1 の analysis_close_bets(買い目ごとの odds)があれば、同じ分析対象の買い目を (分析, 券種, キー) で突き合わせ、分析時 → 締め切り直前のオッズの比を見る。馬ごとのオッズが要るときは R2 を GET だけで読む(件数を報告)。

## 5. 前半・後半
分析日(analyzed_at)の中央値で 2 分して、1〜3 を同じ向きかで比べる。

## 母集団と限界
- 配分の記録がある 545 行。replay の一致率は関係しない(買い目は書き出しの allocation.bets をそのまま使う)。
- 確定オッズでの配分のし直し(反実仮想)は範囲外。
- 比のばらつきは N に依る。表のセルの下位桁に意味を読まない。
