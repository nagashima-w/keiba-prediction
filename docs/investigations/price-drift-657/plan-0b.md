# #657-0b 直前に大きく買われる馬に共通点はあるか(計画。0b の結果を見る前に固定)

材料は 0 と同じ配分の書き出し(配分の記録がある 545 レースの全馬。買い目に入ったかは問わない)。本番のコードは変えない。
騎手・調教師・性齢・斤量・馬体重は書き出しに無いため、本番 R2 の分析の詳細(raceSnapshot.horses)を GET だけで読む(`pull_r2.py`。分析 1 件につき 1 GET、545 件)。#664 の特徴量は scratchpad の feat664.ndjson.gz(race_id・馬番で引く。中央競馬の一部のレースにしか無い)。

## 「大きく下がった」の定義
比 r = 確定の単勝 ÷ 分析時点の単勝(0 と同じ)。
- 主: 人気帯(分析時点の 1-3・4-6・7-)ごとに ln r の下位 10% に入る馬(帯の中の順位で決める。0 で見た「穴馬ほど上がりやすい」構造を取り除くため)。
- 副(感度): 絶対で r ≤ 0.75。
- 主と副で結論の向きが変わるか報告する。

## 1. 共通点
大きく下がった馬の割合(基準率 = 全体の割合)を、次の区分ごとに出す。N と Wilson の 95% 区間を付け、区間が基準率を外れる区分を拾う。
- 分析時点の人気帯、騎手(出走 30 頭以上の騎手)、調教師(同)、性別、年齢(3/4/5/6-)、斤量、馬体重の増減(取れれば。±10kg を境)、#664 の特徴量(フラグごと、カバーされたレースだけ)。
- 多重比較: 区分の数 k を数え、基準率を外れる区分の数が偶然(両側 5%)の期待 k×0.05 を超えるかを書く。個別の区分の「発見」は仮説扱いで、前半・後半の両方で同じ向きのものだけを共通点の候補にする。

## 2. 大きく下がった馬が来るか
確定オッズから市場の見込みを作る: 勝率 q = (1/確定) ÷ Σ(1/確定)(レース内。確定の単勝がある馬)。3 着内率は q3 = 1 − (1 − q)^k で、k をレースごとに Σq3 = 3 になるよう二分法で決める(出走が 3 頭以下は対象外)。
下がった群と、それ以外の群の、実際の 1 着数 ÷ Σq と 3 着内数 ÷ Σq3 を出す(1 を超えれば、確定オッズの見込み以上に来る)。区間はレース単位のブートストラップ(2000 回、固定乱数)。人気帯ごとにも出す。
限界: 勝率・3 着内率の見込みの作り方(正規化・べき乗)に依存する。1 着は件数が少なく区間が広い。

## 3. 前半・後半
分析日(analyzed_at)の中央値で 2 分し、1・2 を同じ向きかで比べる。

## 母集団と限界
- 545 レース。R2 が読めなかった分析・特徴量が無いレースは、その項目の N から外れる(N を必ず書く)。
- 大きく下がる定義(帯内の下位 10%)は、分析時点が発走 30 分前、確定までの買いの総量を反映する。因果ではなく共通点を見るだけ。
- パドック・返し馬は材料に無い。
