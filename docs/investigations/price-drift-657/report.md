# #657-0・0b 買い目の馬のオッズの動きと、直前に買われる馬の共通点(結果)

計画は plan.md・plan-0b.md(結果を見る前にコミット済み)。表の全文は result-0.md・result-0-close.md・result-0b.md。
材料は配分の書き出し(2026-10-27 時点)の、配分の記録がある 545 レース。そのうち分析時点と確定の単勝が両方ある馬は 6607 頭・500 レース(残り 45 レースは該当する馬がなく、集計から外れた)。
経緯: Issue のコメントは「見込みの的中と実際のずれ(1.73 倍)のうちオッズの動きが占める分」を見るとしていたが、見込みの的中(Σ 確率)はオッズに依らないので、見込みの払戻(Σ 賭け金 × 確率 × オッズ)と実際の払戻のずれに直した。

## 0. オッズの動き
1. **買い目に入った馬は、入らなかった馬より確定までのオッズが下がっている**(確定 ÷ 分析時点の中央値: 入った 1.036、入らなかった 1.340、差 -0.304、95% 区間 -0.346〜-0.258)。ただし半分は人気の構成の違い: 人気 1-3 帯では差がなく(-0.005)、4-6 帯 -0.126、7- 帯 -0.444。穴馬ほど確定で上がる(入らなかった 7- 帯の中央値 1.774)という全体の傾向があり、買い目に入るのはその傾向が弱い馬、という読みと合う。前半 -0.125、後半 -0.406 で向きは同じ、大きさは違う。
2. **単勝は確定オッズで実測できる(279 点)**。見込みの払戻は、分析時点のオッズに対し確定オッズで 0.946 倍(95% 区間 0.868〜1.024)。実際の払戻は分析時点の見込みの 0.448 倍。0.448 = 0.946 × 0.474 なので、**ずれのうちオッズの動きの分は約 5%、残りは確率の見積もり(的中が見込みより少ない)の分**。前半(36 点)は 0.784・後半(243 点)は 0.972 で、前半は点数が少なく区間が広い(0.486〜1.195)。
3. 複勝・組合せは確定オッズが書き出しに無い。的中した買い目だけ払戻 ÷ 100 から確定オッズを実測でき、分析時点のオッズに対する比の中央値は単勝 0.868(18 的中)、複勝 0.667(39)、ワイド 0.831(22)。**選択の偏りがある**: 的中した買い目は「勝った馬・来た馬のオッズの動き」だけを見ている。複勝は分析時点が下限のオッズなので、払戻との比に下限と実の幅が混ざる。
4. 全買い目を単勝の比の積で動かす感度試算(複勝・組合せ。実測ではない)は、E1/E0 が複勝 1.55、ワイド 1.03、馬連 1.68、三連複 2.26 と 1 を超える。これは「オッズが下がる」向きと逆で、**代理の作り方が効いている**(穴馬ほど比が 1 を超える傾向を、馬ごとの比の積で組に持ち込むため)。実測の裏づけがないので、この数字から組合せの見込みが過大/過小とは言わない。全体の A/E0 は 0.213 で、その大部分は確率の見積もり側(A/E1 0.185)に出るが、これも代理に依る。
5. 締め切り直前(D1 の analysis_close_bets、分析時の買い目と同じ (券種, キー) が残ったもの): 回 1 は 460 点すべて比が 1.00(同一)。回 2 は 215 点で中央値 0.990(p10 0.794・p90 1.180)。回 1 は取得したオッズの公式時刻が起床時刻の約 59 分前(JST とみなした場合。228 件の中央値)で、分析(起床の約 25 分前)より古い。回 1 のオッズが新しい情報になっていないことの確認であり、原因は調べていない。回 2 は約 2.7 分前。単勝で 3 時点がそろう 84 点は 分析→直前 1.020(平均)、直前→確定 1.034、分析→確定 1.058(中央値は 0.980・1.045・1.023)。**再計算で残った買い目だけの比較で、消えた買い目(回 2 で単勝 151 点中 67 点、複勝 37 点中 37 点)は含まれない**(生き残りの偏り)。馬ごとのオッズは D1 に無く、R2 は 0b の属性の取得にだけ使った(ここでは使っていない)。

## 0b. 直前に大きく買われる馬の共通点
定義(主): 人気帯ごと(全レース込み)の ln(確定 ÷ 分析時点)の下位 10%(659 頭)。副: 比 ≤ 0.75(961 頭)。
1. **共通点の候補は、前半・後半とも全体と同じ向きに基準を外れた区分だけにした**(区間はレースの相関を無視するので、外れる数は多めに出る)。主: 3 歳が高い(14.6% 対 期待 10.0%)、6 歳以上が低い(4.5%)、斤量が軽い(wLight)馬が低い(4.7%)。副ではさらに 400m 以上の距離延長(distUp400)が低い、騎手の武豊が低い(74 頭中 1 頭)。
2. 検定した区分 262 個のうち 41 個が外れた(偶然の期待は 13.1 個)。調教師・騎手は個別に多数外れているが、前半・後半で同じ向きに出るものは武豊だけだった。個別の騎手・調教師の「共通点」は、この材料では言えない。
3. 騎手・調教師・性別・馬体重・斤量では、2 つの期間をまたいで一貫して外れた区分は少ない。**馬体重は、分析時点で未発表の馬(3441 頭、52%)が高い(13.8%)が、前半では基準内(13.2% 対 12.7%)**。馬体重の増減は書き出し・R2 のどちらにも無く(R2 の bodyWeight は体重の値だけで、増減はなし)、見ていない。
4. **#664 の特徴量**: 7 歳以上(age7)・芝ダ替わり・東西の遠征(eastInWest)・距離延長(distUp400)・軽量(wLight)は全体で低い側に外れたが、前半・後半ともそろったのは wLight(主・副)と distUp400(副)だけ。
5. **大きく下がった馬は、確定オッズの見込み以上には来ない**: 主の群の 1 着数 ÷ 見込み 1.109(区間 0.934〜1.273)、3 着内 1.011(0.930〜1.089)。人気 1-3 帯の 1 着だけ 1.270(1.007〜1.536)と区間が 1 を外れるが、前半 1.511・後半 0.892 で向きが一致せず、3 着内は 0.948 と 1 を下回る。7- 帯の 3 着内は 1.205(下がった)と 1.229(それ以外)でほぼ同じで、**これは確定オッズが穴馬の 3 着内率を低く見積もるという一般的な傾向であり、下がったことの情報ではない**。「直前の買いに情報が乗っている」という証拠は見つからなかった。

## 限界
- 勝率・3 着内率の見込みは、1/オッズの正規化とべき乗(Σ=3)の近似で、レースごとの控除率や穴馬の偏りに依存する。
- 区間はレース単位のブートストラップ(2000 回、固定乱数)または Wilson。Wilson はレースの相関を無視する。
- 比のばらつきは N に依る。表の下位桁に意味を読まない。1 着数は件数が少ない。
- パドック・返し馬は材料に無い。
- 複勝・組合せの期待の計算し直しは実測ではなく、的中側の実測と感度試算の二本立て。
- R2 の読み取りは GET 545 件(失敗 0)、D1 は SELECT 3 回。
