## 2. 問い
1 番人気(`win_odds_rank = 1`)のうち、発走前に分かる条件で、3着内を外しやすい(または外しにくい)馬を見分けられるか。条件は 2 つの側から選ぶ。
- **敗因の側**: 馬券外になったときの敗因になりうる条件。
- **人気の理由の側**: そもそもなぜ 1 番人気になったか(市場が何を買ったか)に当たる条件。
- (**レースの側**: 荒れやすさに関わるレース条件。#682 など先例の条件。)
どの側に入れたかは記述のためのラベルで、検定には使わない。

近似・省いたもの(限界):
- **人気の騎手は外国人騎手で近似した**。リーディング上位の一覧は、BASHIRA に騎手の軸が無く作れない。記憶の一覧は材料にしない。短期免許のほか、日本在住の外国人騎手(ルメール・デムーロなど)も入る。
- **出遅れ癖の近似は長めの距離に偏る**: `first_corner_position` は 1 コーナーのある距離の走にしか値が無い(短距離は NULL)。頭数の比が書けないので、絶対位置(10 番手以下)と頭数(14 頭以上)の組で近似した。n が足りなければ検定の外に落ちる。

- 1 番人気の定義は公式の `win_odds_rank = 1`。1 倍台でも 2 番人気がいる場合は想定していない(1.0〜1.9 倍の馬は原則 1 番人気)。

## 5. 期待値と検定(事前登録)
- 層は小帯(4 つ)。条件 c の小帯 b の走数を n、条件に当たらない 1 番人気の走数を m、3着内(勝ち)の率を p_rest、プールした率を p̂ とする。
- E = Σ_b n p_rest。z = (O − E) / √(Σ_b n p̂(1−p̂)(1 + n/m))(2 群の比較の分散。#682 と同じ)。小帯の中で条件に当たる走が 0、または当たらない走が 0 の層は落とす。
- 全体(4 小帯)の z が検定の単位。1 倍台・2 倍台・3 倍以上の内訳は記述で、検定の数に入れない。
- **探索**: 全体の n ≥ 200 の条件 × 2 指標(3着内・勝ち)を検定の族とする。両側 p を族全体で BH 補正し、q < 0.05 を候補とする(向きは問わない。|z| の下限は置かない)。n < 200 の条件は「検定外」と報告する。
- **確認**: 候補だけを、探索と同じ向きの片側 p で Holm(補正の数 = 候補の数 K)。「残った」= n ≥ 200、探索と同じ向き、Holm 後 p < 0.05。判定の基準は確認を見たあとに変えない。
- 回収率の記述: 条件に当たる 1 番人気の複勝回収率(と、当たらない 1 番人気の複勝回収率、単勝回収率)。
- 「その馬を外した買い方」の記述: BASHIRA では 3 連複・ワイドの払戻が引けないので、回収率は出さない。残った条件の「1 番人気が 3着内を外した割合」(1 − 3着内率)と、年あたりの該当頭数だけを出す。3 連複・ワイドの回収率は、手元のデータ(2021-06〜)での別の確かめになる(スコープ外)。
