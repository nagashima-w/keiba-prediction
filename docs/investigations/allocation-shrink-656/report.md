# 買い目の選び方の試算(Issue #656 段階 1)

本番のコードは変えていない。計算し直しの道具(`scripts/allocation-dataset.ts` の `replayRace`・`adjustProb`・`evThreshold` の上書き)だけで、買い方を比べた。

## 材料と手順

- 材料: 本番の配分の書き出し(2026-10-27 時点、931 行)。うち配分の記録がある 545 行(`noAllocation` 386 行は旧い分析で計算し直せない)だけを使う。中央・地方の内訳は表のとおり(地方は買い目が 51〜72 点しかない)。リポジトリには入れない。
- 545 行すべてで、保存した設定の `ev_threshold` は 1(今の買い方 = 閾値 1)。
- 比べた買い方(固定。増やしていない):
  - `base`: 上書きなし。
  - `w75`・`w50`・`w25`: 補正後の 3着内率 p と市場の 3着内率 m を logit(p') = w·logit(p) + (1−w)·logit(m) で混ぜ、レース内の合計が min(3, 頭数) になるよう共通のロジットのずらしで合わせる。m は 1/単勝オッズをレース内で割り戻した q から、切片 2.857 + 0.9216·logit(q) − 0.5561·log(頭数) のロジスティックで出す(頭数 = 単勝オッズのある馬の数)。単勝オッズのない馬は混ぜない(m = p)。
  - `t11`・`t12`: `evThreshold` を 1.1・1.2 に上げる。
  - `w50t11`: w = 0.5 と閾値 1.1 の組み合わせ(結果を見る前に 1 つに固定。閾値は 1.1 と 1.2 のうち、単独で回収率の点推定が高かった側)。
- 見込みの的中数 = 判定できた買い目(返還・判定不能を除く)の ev ÷ odds の合計。実的中数 = 判定が的中の点数。「見込み/実」が 1 に近いほど、確率の見積もりが実際に合っている。
- 回収率の 95% 区間 = レース単位のブートストラップ(2,000 回・乱数の種は固定)。「上位 N 除」= 払戻の大きい順に N 点を、賭け金ごと除いた回収率。
- 再現: `pnpm tsx docs/investigations/allocation-shrink-656/replay.ts <書き出し> <出力先> <id> [w=…] [t=…]` を買い方ごとに流し、`report.ts <書き出し> <出力先> <id>...` で表を出す。混ぜる式は `mix.ts`。

## 読み方と選んだ買い方

- **見込み/実が最も 1 に近いのは w = 0.5(1.13)**。w = 0.25 が 1.15 でほぼ同じ、今の買い方は 1.73。回収率は w = 0.5 が 94.0%(今の買い方 78.8%)で、点推定は悪くならない。w = 0.25 は見込み/実が近いが回収率は 83.5% に下がり、w = 0.5 のほうが良い。よって**採る目安(見込み/実が最も 1 に近く、かつ回収率が今より悪くならない)を満たすのは w = 0.5**。
- 閾値だけを上げた `t11`・`t12` は、回収率の点推定は上がる(90.7%・87.0%)が、見込み/実は悪化する(1.90・2.06)。実的中が 73 → 63・53 点に減る一方、見込みは残る。確率の過大を直す手段にはなっていない。
- `w50t11` は回収率 95.6% と w50 より僅かに高いが、見込み/実は 1.18 で w50(1.13)より離れる。上乗せの根拠は弱いので採らない。
- 回収率は雑音が大きい。w = 0.5 と今の買い方の差の対ブートストラップ区間は −6.7%〜+38.3% で 0 をまたぐ(差が正になった抽出は 91.6%)。**回収率の改善は有意とは言えない**。確率の見積もりの改善(見込み/実 1.73 → 1.13)のほうが確かな結果で、これは月報の「見込み 127 点・実際 68 点」(約 1.9 倍)と同じ種類のずれが縮むことを示す。
- 上位 1・3・5 点を除いても、w = 0.5 は今の買い方より高い(86.9%・75.7%・65.6% 対 69.1%・58.5%・52.3%)。高配当 1 点への依存は、今の買い方のほうが強い。
- 券種別で見ると、w を下げると単勝は点数が減る(305 → 318 → 196)一方、ワイド・枠連が増える。馬連は全買い方で 35〜53 点を買い、的中は 0〜1 点で回収率 2〜10%(今の買い方も 9.8%)。馬単は的中が 1〜3 点で回収率の振れが大きく(48.6%〜475%)、解釈できない。
- 地方は今の買い方で 51 点・的中 0 点・回収率 0% なので、w を混ぜたときの差(w = 0.5 で +14%〜+122%)は、基準が 0 であることに引きずられる。地方だけの結論は出せない。中央だけで見ても w = 0.5 は 82.3% → 96.6%、見込み/実 1.62 → 1.11 と、全体と同じ向き。

## 限界

- 545 レース・的中 73〜90 点。券種別・区分別のセルは数点の的中で決まる。隣り合う w の差(例: 0.5 と 0.25)に意味を読まない。
- 配分の記録がある行だけで、書き出し時点(10/27)までの分。w を変えると賭け金の配分(ケリー)も変わるので、点数・賭け金も変わる(w = 0.5 の賭け金は 120,600 円、今の買い方は 134,900 円)。
- 画面の 3着内率や LLM の入力は変えていない(配分の前の確率だけを混ぜる試算)。
